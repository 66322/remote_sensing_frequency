## 研究问题、参照与非创新边界

假设H1：S1-3已经学到的局部融合解码能力，部分能够在S1-0冻结特征上复用；若成立，应优于相同容量的S1-0初始化和随机初始化，而非仅比小残差头好。假设H2：此复用依赖缺失区仍存在的上下文特征；若成立，同一初始化的保留上下文应优于屏蔽上下文。假设H3：单次RGB/DSM专家前向加私有解码器能接近双模型R0，同时保留已知缺失回退与区域外预测。

冻结基础模型并训练旁路已有先例：[Side-Tuning](https://arxiv.org/abs/1912.13503)；从冻结主干中间特征训练侧网络也已有先例：[Ladder Side-Tuning](https://arxiv.org/abs/2206.06522)。本协议借鉴适应结构，不把冻结、旁路、精确保护或解码器复制本身声称为创新，也不把上述论文当作RGB–DSM实验支持。待检验的是“已知局部缺失的上下文知识能否以共享特征复用，以及跨权重的适用边界”。

本轮不增加蒸馏、置信网络、区域划分、窗口大小、训练时长或种子来挽救旧配方。既有S1-3含不同编码器权重，因此移植其解码器不等于完整复现S1-3；失败可能反映跨主干特征不兼容，不能直接否定上下文问题。若T1或随机控制已达到同等效果，按强基线结果报告，不能后验替换固定T7宣称移植成立。
