# D13 compact handoff

`user_reported_stage1_decision.json` transcribes the machine-readable D13
Stage 1 decision pasted by the user. The queue status and summary were also
pasted; original per-arm `summary.json`, confusion matrices, logs, and
checkpoints have not been transferred from the server. The server originals
take precedence if they differ. See `docs/experiments/D13_RESULTS_20260925.md`.
