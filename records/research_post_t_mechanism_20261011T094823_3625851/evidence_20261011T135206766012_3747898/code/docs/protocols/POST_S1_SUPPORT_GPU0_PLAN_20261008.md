## 3. D0：复用预测与最强简单控制

建立R0零训练硬拼接控制：已知RGB局部缺失且DSM有效的位置采用旧S1-3预测，其他位置采用旧S1-0。全RGB缺失/无效DSM仍原基线。只能依据可观测mask，不用GT错误/退化类别作路由。现有标签预测可精确重建该离散选择；部署需两个完整模型的推理成本须单列。GT oracle逐像素最优只可作上限诊断，不能成为方法或门槛对手。

### 5.2 三个因素及残差头
统一基础模型F0输出logits z0，旁路残差头R读取RGB/DSM晚期128维特征、基线6维logits和2个可用性通道。建议单一1×1投影264→64、GELU、3×3 64→6，最后一层零初始化，全部十组相同容量/初始化。残差logits回到native空间后按支持mask写入，不能先在粗网格mask后插值扩大改动区域。相同专家前向复用晚期特征，不再跑一套编码器；B0只是旁路的上下文投影，原F0输出图保持定义。

因素A：共享更新（沿原last4/heads＋新残差头更新）/参数隔离（F0所有参数及统计冻结，只训练残差头）。
因素B：旁路特征沿原支持mask(B1)/保留计算到的上下文(B0)。
因素C：在有效像素全域写入修正(G)/仅在RGB局部缺失且DSM有效的位置写入(L)。

L：m=(not rgb_mask) AND dsm_mask，并要求该native窗口仍有RGB观测；整窗RGB全缺失、DSM全缺失或两者无效仍F0。G也保留两种全窗缺失守卫，但有观测的窗口允许全域修正。输出用where(m,z0+R,z0)；跨窗口累加使用与F0相同权重。隔离+L的非缺失位置理论上保持F0，必须验证整tile输出/预测一致性；该保护是构造属性，不是贡献证据。共享更新+L仍可能因F0参数变化伤害其他位置，这正是配对控制要检验的内容。

## 8. 文献依据与创新边界
- [Liao等，Benchmarking Multi-modal Semantic Segmentation under Sensor Failures，CVPR2025 Workshop/arXiv v3](https://arxiv.org/abs/2503.18445)：区分全缺失、随机缺失和噪声。我们据此分别报告partial、full和present-but-bad，不把正确缺失标记当质量估计。
- [Reza等，Robust Multimodal Learning with Missing Modalities via Parameter-Efficient Adaptation，TPAMI2024，DOI10.1109/TPAMI.2024.3476487](https://arxiv.org/abs/2310.03986)：小参数适应已是现有路线；加adapter本身不是创新，P6/P9与R0因此是必要控制。
- [Park等，MoME，CVPR2025](https://arxiv.org/abs/2503.19776)：LiDAR-camera 3D检测利用分离专家和质量路由；这里只借鉴“依赖隔离”问题，不把检测结果或其AQR性能迁移为RGB–DSM分割证据。
- [Zhao等，MoRA，ICLR2026](https://proceedings.iclr.cc/paper_files/paper/2026/hash/7038033f576a57a1c8469f2c6c280fcc-Abstract-Conference.html)：共享/特定适应已有先例，任务为视觉语言识别，不是本项目dense局部缺失验证。更强调冻结共享语义与单侧适应的对照，不能仅凭名称声称新方法。
