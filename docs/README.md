## Directory roles

- `current/`: current conclusions and the one active next experiment.
- `experiments/`: experiment-line indexes and individual reports.
- `protocols/`: stable data, naming and evaluation rules.
- `templates/`: required report formats.
- `archive/`: obsolete plans and legacy master documents.

The old single-file master record is frozen. New experiments must use one
report per experiment and update the central registry.
