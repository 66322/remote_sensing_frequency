# 研究阶段与决定

主问题保持RGB外观/语义与DSM高度/几何的双向条件互补，及任一侧退化/缺失时的分割能力。仍处于可行性探索；频率、可靠性、MoE、共享/私有是候选解法，任务驱动SR/恢复是旁支，不因任务顺序改变主线。普通融合、部分解冻与增强是强基线；旧机制未过门槛不等于整个问题失败。目前没有确认性新贡献。
