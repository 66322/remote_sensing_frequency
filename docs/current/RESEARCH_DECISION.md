# 当前研究决定：主线不变，多问题对照入待启动队列（2026-10-22）

研究仍处于可行性与机制筛选。主线是 RGB–DSM 双向条件互补及退化/缺失分割，恢复为旁支。M1 幅度路线按原门禁关闭；M2 检验错误位置对应性监督，代码已实现但用户确认尚未运行。不能把未运行或未来单一配方失败扩大为整个研究问题失败。

用户选择研究问题与创新性优先、无期限压力，可下载公开数据；已有问题可通过更好的建模或跨领域方法继续研究。本轮又要求将[研究与方法候选](../experiments/POST_M2_RESEARCH_OPTIONS_20261022.md)写成与 M2 一起启动的队列，包含新数据方向。这授权实现与未来的一次性启动准备，不等于当前已启动训练或承诺换主线。

[合并队列合同](../protocols/PHASE3_COMBINED_QUEUE_EXECUTION_20261022.md)为 M2→J 冻结专家条件几何→R 可训练表征→T 3DCD 真实高度变化→V P³ 建筑对象关系。J/R 是主线问题的机制诊断；T/V 是独立新任务探索，不借用 Fit12 作为跨城市确认。新任务有自己的开发组、输入/标签口径和封存的公开 test。M2 原科学门禁及 B/C 条件不放宽；M2 G0 未通过则后续停止。J/R 不以主假设正结果挑选，而以完整性及预登记比较报告为依据。

尚未采纳为论文贡献：T/V 试验性小网络胜过成熟基线、某个正结果自动取代主线、自动增加种子/骨干/预算、重跑失败配方、旧全 Fit12 微调权重充当新外层模型。下一步不确定性是条件几何与独立 DSM 监督能否在配对控制下稳定提供增益，以及观测偏差/对象关系能否构成清晰研究问题。每段完成后先核验原件与轨迹，再决定继续、强化基线或换题。
