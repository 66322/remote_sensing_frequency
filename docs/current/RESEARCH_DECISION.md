## 当前定位

当前处于**论文可行性探索**。研究问题主线是辅助模态质量变化时的有益融合与负迁移控制；最终解法、论文贡献和章节结构尚未冻结。优先评估的候选问题是：在光学影像与DSM语义分割中，频率与语义信息能否帮助判断辅助模态的任务收益，减少融合负迁移，并在推理时支持模态退化或缺失。优先评估不等于必须坚持原模块组合，也不要求三个历史章节各自凑出一个贡献。

频率、语义可靠性、融合结构、缺失/退化训练是可检验的机制或训练条件，不能凭名称写成已验证贡献。允许保留问题而换解法，也允许证据不足时换交叉问题或研究方向；不得仅因某个旁支有正结果便默认完成转向。

## 候选路线与证据角色

| 项目 | 角色 | 目前不能据此推出什么 |
|---|---|---|
| 频率与语义信息支持的可靠性融合 | 优先评估的候选路线；具体机制待证据梳理后确定 | 不代表整套方法已经实现或已验证，也不保证频率必须保留 |
| 缺失、退化训练与推理回退 | 原候选问题的能力要求与匹配训练条件 | 增强有效不等于可靠性融合有效；可运行不等于保持精度 |
| A部分解冻 | 强基线策略线索 | 不能当作DSM特异性贡献或新的论文方向 |
| C1任务驱动恢复 | 旁支开发候选和潜在备选方向 | 八个pooled正值不等于已替代原路线或独立泛化通过 |
| D21 F2、Post-D21 B3/C3及其他已关闭实现 | 保留原门槛与负结果 | 不能改阈值挽救，也不能扩大为整个频率/语义问题不成立 |
| 独立来源评价 | 候选需要确认性证据时的阶段工作 | 不成为所有新机制案头设计或已有数据探索的绝对前置 |

## 能力目标须拆开验证

1. **正常输入**：相对匹配的光学基线、普通融合与容量对照，检验辅助模态是否带来可归因的分割收益。
2. **退化与局部缺失**：在相同增强条件下比较普通融合与候选机制，报告整体、受损/完整区域、逐类和逐tile表现；图像清晰度、频率能量和边缘对齐本身不等于融合收益。
3. **整幅缺失**：分别记录能否正常前向、如何回退，以及相对光学基线的精度代价。已知缺失标记下的确定性回退属于工程保证，不等于学会真实缺失检测。
4. **未见退化与地域泛化**：训练见过的合成条件、未见合成条件和独立地区分别报告，不相互替代。
5. **适用模态范围**：阶段实验可以先研究DSM缺失/退化，但必须明确光学输入是否仍可用。若要声称任意模态缺失均可工作，还须覆盖光学缺失/退化及DSM单模态条件；不承诺两种模态同时无有效信息时仍有正常精度。
6. **可部署性**：推理只能使用当时可获得的影像、模态可用性信息及模型输出。训练标签、合成退化真值或oracle可用于监督/诊断，不能泄漏为实际推理输入。

## 去留判断

| 决策 | 证据要求 |
|---|---|
| 继续当前解法 | 有实质新机制、匹配对照、预先规定的实用增益与伤害约束，并有相应证据支持；不是只改善代理评分 |
| 同一问题换解法 | 问题仍有价值或可利用互补性，但当前表示、融合或训练目标失败；新解法须明确改变什么因果假设 |
| 换交叉问题 | 原组合难以形成贡献，但已有证据支持一个范围更清楚、可独立检验的问题；重新定义目标与对照 |
| 换方向或停止 | 关键假设缺乏支持、收益主要由容量/通用训练解释、资源成本与预期价值不符，且没有高信息量的下一实验 |

上述为决策框架，不是已完成的机制判定。数值门槛、任务数和预算必须在对应新实验看结果前冻结；不在此事后创造通用于旧实验的新门槛。不靠换名称、堆模块或连续微调延续已关闭方案。
