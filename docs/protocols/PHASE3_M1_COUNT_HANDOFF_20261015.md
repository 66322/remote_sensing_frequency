3. 在停止旧控制器前，目标Linux机运行两个自建CPU子进程的匿名memfd传输检查，原算法逐整数比对。该检查不读训练数据，不调用GPU。
4. 仅在PID19614的完整命令、实验路径及进程启动标识匹配时，经pidfd发送TERM。核验PID变化时不发信号。旧控制器自行退出其子进程、释放队列和缓存；新入口等待其锁与生命周期回执，最多240秒，不通过则不启动第二个执行器。GPU0/1存在其他任务时停止，不操作其他任务。GPU2—7不参与。

6. 因旧预测在匿名内存中，旧进程退出后需重建剩余tile的12份DSM预测。先重放同tile一份历史RGB案例，完整联合计数逐整数一致后才允许写入新结果；不一致立即停机留证。

8. 最多8个在途案例；每份预测最后一个消费者结束即释放。同tile消费完释放其DSM预测。最后GPU前向结束即停止自己的GPU工作进程，不等CPU尾部计数占用显存。最终所有自建子进程退出后才删除本run的运行缓存和temporary，保留权重、输入、日志、计数和溯源文件。
