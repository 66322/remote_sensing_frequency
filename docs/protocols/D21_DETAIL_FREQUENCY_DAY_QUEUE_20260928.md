## 为什么做这一批

D18/D20 实际执行链中，DSM 在进入辅助支路前做 14×14 平均池化。D18 双种子验证了预训练表示下的
DSM 互补收益，但并未建立精细结构恢复或缺失高度时的可靠性。D20 Vaihingen 有局部负迁移。
下一步问题是：将高度信息保留到 1/4 分辨率，能否改善语义/边界；改善来自更细采样、额外容量，
还是低/高频的正确配对？本批不添加一致性损失，不重启 D16/D17 失败配方，也不复跑 D19 局部交互。
此前 D12 的冻结专家决策头频率特征初筛亦失败；D21 改为 DINO 语义表示上的可训练空间解码支路，
直接以分割 CE 联合训练新头，并预设同结构消融。D12 失败记录不因更换表示而变成正面证据。

## 八组设置

所有组使用冻结 DINOv2 ViT-S/14、相同 RGB 投影与分割头初始化、相同损失和采样随机流。

| Arm | 设置 | 回答的问题 |
|---|---|---|
| R0 | 仅光学影像，D18 P0 结构 | 新预算下的光学基准 |
| R1 | 光学 + 14×14 池化 DSM，D18 P2 结构 | 新预算下的旧融合基准 |
| M0 | 光学 + 1/4 尺度原始 DSM，两通道输入为 `[DSM,0]` | 保留细尺度信息是否有收益 |
| M1 | 与 M0 完全同结构，DSM 换成光学灰度 | 支路容量/光学细节对照 |
| F0 | `[low,0]` | 低频消融 |
| F1 | `[0,high]` | 高频消融 |
| F2 | `[low,high]`，预注册候选 | 低/高频联合表示 |
| F3 | `[low,roll(high)]` | 高频位置对应关系对照 |

M0/M1/F0/F1/F2/F3 的层、通道和参数总数相同，均在 1/4 尺度加到光学特征后共用分割头。
先对辅助图做 4×4 平均池化，`low` 为该图的 5×5 replicate-pad 均值，`high=raw-low`。
F3 将 high 在两个方向各循环平移半个特征图，保留值分布；它是固定空间打乱消融。
这是空间均值滤波的频率分解，不是 FFT、物理频率校准或已有创新的证明。
R1 与细尺度组的比较同时涉及采样尺度和支路宽度；F2 与 M0/M1/F0/F1/F3 才是同结构比较。
缺失高度时偏置和归一化仍可能产生辅助输出；没有将零高度解释为可用性标签，也没有隐式 fallback。

## 数据、随机性与预算

- Potsdam：原 Train16/Val2；Val2 为 `3_11,5_10`；Test6 不读取。
- Vaihingen：沿用 D20 的 12 训练块、17 开发块，排除历史 4 块；保持 NIR/red/green 顺序，不能称真 RGB。
  17 块仍属已使用的同镶嵌图开发区域；D20 原门槛失败保持原判。本批是新机制、新预算和全新配对对照。
- 各数据集均执行 seed42、17 的所有八组，共 32 次；两个种子均预设完整配对，不按 seed42 分数挑选补跑组。
- 每组从同一冻结 DINO 权重、按对应 seed 初始化新头，训练 **16,000 步**，不接续 D18/D20 的 8k 头。
  预算提高用于同批公平比较和学习稳定性检查，不能把绝对分数与旧 8k 结果直接归因比较。
- patch512、microbatch2、梯度累积8，有效 batch16；每步 clean/受损 CE 各占 0.5。
- 沿用 D18 的学习率3e-4、AdamW、weight_decay0.01、warmup100、poly 调度、九项受损概率及基础裁剪/缩放/翻转。
- 相同 dataset/seed 的各 arm 使用相同 patch/受损随机键。评价损坏随机种子固定42，与训练 seed 无关。
- 固定最终权重，不用开发集选 checkpoint；训练不读取开发标签。
- 每组评价11条件：clean、4项光学质量、2项高度质量、全缺失、局部缺失、光学对比度、高度平移。
- Potsdam stride256；Vaihingen stride512；inference batch4。不能混算两数据集的绝对指标。
- Potsdam 主指标保持本链 NoBoundary fg5，另报 FullGT fg5/all6；Vaihingen 主指标 FullGT fg5，all6 诊断。
- clean/rgb_down4/aux_shift8 保留 FullGT 前五类边界匹配计数，3像素容差。其他条件保留全图混淆矩阵。

## 判断预注册

F2 综合分数为 clean、光学质量、高度质量三家族等权平均。每 dataset/seed 分别计算。
要求 F2 高于所有七组对照中的最强者至少0.2pp；相对 R0/R1/M0 各自 clean 下降不超过0.1pp，
质量家族不超过0.3pp，逐 tile 同样使用0.1/0.3pp保护。全部四个 dataset/seed 块通过才记总开发门槛通过。
这个严格门槛不等于正式 test 验证。

缺失 DSM 的安全检查单列：F2 aux_zero 相对同 seed R0 不低于−0.1pp；不能用综合增益抵消缺失模态问题。
边界指标用于定位机制，保存原始匹配数；全图/逐类增益不能自动写成边界改善。
若 M0 优于 R1 而 F2 不优于 M0，优先解释为细尺度融合机会，不能声称频率机制成功。
若 F2 不优于 F3，不能声称正确的高频位置关系带来收益。两 seed 不稳定时报告全部结果，不挑最好一次。
下一批可在这些证据基础上设计 RGB 锚定可靠性机制；这项尚未包含在今晚代码中。

## 资源与顺序

使用物理 GPU0/1，对应 UUID 写入计划，各卡独立一个进程。启动顺序：环境/DINO 权重复用 →
训练/开发输入哈希及 CPU 测试 → 16个 arm×dataset 的两步 train-only smoke/保存重载 →
seed42的16组 → seed17的16组。每个 seed 块自动汇总；第三种子不自动运行。

旧 D20 P2 曾观测约0.222秒/步，16k约59分钟纯训练；加全图评价及新细尺度支路开销，
本批粗估 **20–35小时墙钟、40–70 GPU小时**。这是排程估计，尚无新模型实测吞吐。
时间由数据读取、边界计数和主机负载影响；不是承诺严格运行满某个时长，也不通过空等待凑一天。
前100步后每100步写实测速率和剩余时间。两卡各一进程；不更改微批大小或自动扫超参数。

初次预检阈值为至少80GiB空闲磁盘、48GiB可用主机内存；这是避免两进程与预测归档撑满资源的保守启动阈值，不表示一定会用掉这些资源。恢复时磁盘需求随未完成任务数减少。
GPU显存由完整batch smoke实测记录；OOM即停止，不自动改变预算。原始数据和权重只读。
显存占用>1500MiB或利用率>10%时，该卡等待，最长12小时，不终止其他进程。
每个任务最长12小时；非有限数值、绑定变化、磁盘不足、smoke失败或子进程错误，停止追加任务。
已经在另一张卡运行的任务可以完成，保留每500步断点。负增益是实验结果，照常完成预注册种子。
