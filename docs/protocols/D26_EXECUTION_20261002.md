固定参考为两独立专家、概率平均及可用性切换；每condition/tile锁cache。冻结候选正常forward同时产生的原专家预测直接作只读共享参考；J0单独加载原专家计算一次，不能把适配后的输出当固定参考。joint统计以固定原专家相同受mask输入为参照，类/区域纠错与新增错统计可重算。完整/退化score四族等权，不把缺失混入综合。
