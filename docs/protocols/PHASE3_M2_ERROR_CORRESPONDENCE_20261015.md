## 1. 为什么转向这个问题

Phase3-M1已经完成，不再重跑其归一化、统一幅度或stem配方。M21相对旧M00的DSM-only提高约1.20/1.14pp，但相对普通适配M11，RGB-down4补救率变化为+0.53/−0.91pp，固定融合新增收益接近零。Phase2.4的探针可以救回部分RGB错误，却无法同时保护clean/healthy；零值捷径不延伸到down4。以上是已验证的开发证据，不是正式test结果。

**新问题：针对RGB在未见训练tile上的困难位置训练DSM，能否改变两模态错误的重合方式，并在新的tile、RGB实例和退化条件中兑现补救；普通难例学习是否已经足以解释全部收益？**

新的干预是训练监督的像素分配及其对应关系；输入表示固定为M1的普通处理R1+A1，不再尝试统一高度幅度。部署保持简单固定融合，不先发明新的门控。研究主线仍为RGB–DSM条件互补与退化/缺失分割，恢复仍为旁支。

本轮承认两种有价值的结果：可迁移的错误对应性成立，或普通困难样本训练/静态融合已经解释现象。后者是停止专门机制开发的依据。不能仅凭涨分将重加权命名为新的算法贡献。

## 2. 假设、竞争解释与论文边界

| 假设/解释 | 必须出现的证据 | 否定或限制它的结果 |
|---|---|---|
| H1：RGB困难位置的对应关系提供额外训练信息 | DF超过普通CE、自身难例、分层打乱及熵排序控制 | 打乱对应后同样有效，或普通难例已解释 |
| H2：退化条件的困难信息有独立作用 | DF相对DClean有稳定新增补救 | 两者相当，只能保留一般困难学习解释 |
| H3：新增补救可以迁移 | 外层tile、不同RGB seed、未见退化均保持方向 | 仅对原RGB实例或已知down4有效 |
| H4：新增补救可被简单决策利用 | 固定融合及预设权重曲线有净收益，clean/healthy代价可控 | 只有oracle/补救容量增长；固定动作不兑现 |

ReconBoost、AUG、MARS已有跨模态纠错、残差优化或缺失条件专家专门化；Focal Loss已有普通困难样本学习。**“让DSM学习RGB错误”本身不能宣称首创。** 本轮首先寻找机制和适用边界；完整竞争方法复现、独立地理数据、明确新方法仍是论文方法贡献的后续条件，不能由本轮108个作业代替。

## 3. 数据：空间分组，避免旧模型泄漏

允许池仅为Potsdam原Fit12：2_12、2_10、7_8、3_12、5_12、7_9、6_9、7_7、4_12、6_8、6_12、6_7。

1. 从这12张影像的地理元数据读取范围、投影和中心，按中心坐标跨度更大的轴升序（相同跨度用X轴，坐标并列按tile ID）分成连续三组，每组4tile。只读允许池的文件头，不读禁区元数据或按标签/分数分组。每组依次作为外层评价，余8张训练。
2. 若地理元数据缺失，使用固定自然序tile ID的连续三组，并在清单标为tile分组，不能称地理独立。若检测到影像实际重叠，停止数据冻结，先依据无标签元数据修正排除关系；不训练后再改fold。
3. 对外层评价tile的边缘统一内缩512原生像素计分，减少邻接上下文影响；完整tile为辅助。训练crop不跨tile。内缩并不能创造独立城市或彻底消除空间相关性。
4. 所有主模型从相同公共预训练重新开始，禁止使用看过全Fit12的旧RGB/DSM微调权重初始化、生成主教师标签或充当配对对照。旧M1表只作背景。
5. Val2（3_11、5_10）不进入本轮训练、模型选择、门禁或主队列；本轮不重新访问它们。Test6、既有held4、final持续禁止。本文的“外层4tile”来自Fit12，与既有held4不是同一个集合，代码必须按显式ID白名单判定。
6. 训练统计只从当前模型允许的训练tile计算。DSM采用逐tileR1，目标tile使用其无标签输入统计是已声明的整tile预处理，不使用目标标签调归一化。

这仍是同城、历史开发池内的交叉验证。每个tile只由未训练它的新外层模型评价，但研究者已接触过该数据集，因此不能称新的封闭测试或独立地理泛化。

## 4. 教师来源：四路交叉拟合

每个外层fold×seed单元：训练1个部署RGB基线R，使用外层8tile；再将8tile按相同无标签排序规则划成4对，训练4个RGB教师T0–T3，每个教师只用其余6tile，为被排除的2tile提供监督权重。教师均不见外层评价tile。

一个训练crop的教师必须没有训练过该crop所属tile。保存“学生crop→teacher→teacher训练tile”的绑定。教师从公共预训练重新训练，固定32k，无目标结果选优。四个教师使用seed的派生随机键；重复训练的三个整系统seed为42、17、2026。

用train6代替train4减少教师和部署train8的能力差距，仍要报告这一差距。所有teacher都在外层tile上保存同一份只读困难分布诊断，不能据此挑teacher或调整权重。此项诊断可判断困难信号是否来自过弱教师。

三个seed覆盖RGB、教师、DSM初始state和采样流。与M1“两DSM seed共享一个RGB seed42”不同，本轮是完整系统重复；同一fold内不同处理臂共享对应seed的初态、crop/flip序列和更新预算。

## 5. 训练目标：七个DSM处理臂

DSM架构及表示固定为DINOv2-vits14、R1+A1：逐tile稳健归一化，stem和最后4block、投影/decoder可训练，前8block参数冻结但允许梯度穿过。RGB沿用匹配专家架构及其既有普通训练范围。主预算32,000更新，batch16，native512。所有新对照同样32k；不是把旧失败配方单独续训。

沿用已绑定的AdamW参数与学习率基值（encoder/stem 2e-5，projection/decoder 2e-4）；将已有日程按总进度映射到32k，执行清单记录逐参数组和完整日程。精度、插值、归一化、loss ignore约定保持同组一致。8k/16k/24k保存轨迹计数；32k是唯一主端点，不按曲线挑年龄，不自动延长到64k。

令p_T(y)为交叉拟合RGB教师给训练真类的概率，q=stopgrad(1−p_T(y))。普通权重为w=(1+2q)/mean_valid(1+2q)；系数2固定，无超参扫描。w只作用于训练有效像素的逐像素CE，标签使用及第6类/ignore约定与普通CE一致，不在评价时使用GT选择动作。

教师训练用clean RGB；产生困难信息时，DF的教师输入按固定键选择clean/down2/down4，各1/3概率。down2/down4仅退化当前crop中25%区域，4个既有mask family等频；掩码和插值由执行快照冻结，DSM学生输入始终clean。没有zero教师条件，避免用零值识别捷径解释本轮机制。

| 臂 | 唯一训练目标变化 | 排除的解释 |
|---|---|---|
| D0 | 普通CE | 新协议基线 |
| DSelf | q=stopgrad(1−p_D(y))的同形式自身难例CE | 普通难例学习即可解释；并非原版Focal Loss复现 |
| DClean | 全部使用clean RGB教师的q | 一般RGB困难对应性 |
| DF | 使用clean/down2/down4教师的q | 唯一首要候选：退化条件困难对应性 |
| DShuffle | 将DF的q在每crop的“GT类别×固定边界距离bin”内确定性置换 | 保留类别/边界难度分布，破坏像素对应 |
| DEntropy | 在同一分层内按教师预测熵排序，再赋予排序后的DF q集合 | 普通无标签置信度排序是否已足够 |
| DMix | 原0.5 CE(p_D,y)+0.5 CE(0.9p_T+0.1p_D,y)除以stop-gradient平均梯度系数，教师输入与DF同分布且停止梯度 | 直接训练固定融合是否更简单有效 |

边界距离在训练GT上按全tile定义，bin=[0,4]、(4,16]、>16像素；ignore不参与。DShuffle键由seed、fold、tile、crop位置、flip组成，不包含step；相同crop重复出现时使用同一置换，避免额外时间噪声正则化。熵并列按原像素索引排序。小分层不足2像素保持原值并计数。即使分层置换仍会破坏空间团簇，报告该剩余混杂，不称完美因果隔离。

DShuffle/DEntropy与DF的每类、每边界bin权重集合应精确相同。DEntropy使用GT仅用于训练分层和匹配权重质量；它是训练对照，不是声称部署无标签的完整算法。DSelf与DClean未强制具有相同q分布，权重质量和有效样本数必须报告。

## 7. 评价：精度、可补救空间和真实收益分开

所有评价在外层tile及固定32k端点完成，native512/stride256、先FP32窗口累积，再固定FP64后处理。主结果为中央计分域NoBoundary fg5 mIoU；full fg5、6类及全tile为辅助。每tile先形成int64 6×6 CM；主聚合为每seed的12个外层tile CM池化后算mIoU，三seed分别列出，再报告其均值。fold、tile与类别差值必须完整保留。

每种局部退化复用4family×5个固定mask（20个/外层tile），损坏比例25%；生成键与训练不相交。这里的mask是重复测量，不是20个独立场景。故障面板：

- clean；RGB-down2/down4（已见类型）；RGB-down8、Gaussian blur σ=2原生像素、RGB加性噪声std=0.05（[0,1]数值并裁剪）为预设未见退化，三项全报不择优；
- DSM-down4、DSM平移(+8,0)原生像素为保护诊断；平移越界ROI排除，所有对照采用共同有效支持；
- RGB/DSM完整缺失的显式availability精确回退仅为工程检查，不算学得可靠性；人工mask与合成噪声不称真实采集质量。

主面板为RGB-down4，逐案例CM先池化后计分。旧M1每family有20mask，本轮每family固定5mask，属于新面板，不能冒充旧完整面板的直接复验；生成ID在执行前冻结。同时分别保存all/damaged/healthy、每类、边界/内部。训练方向与保护方向分别报告，不用一个总分掩盖反转。

逐像素保存充分联合计数：GT×RGB预测×DSM预测（6³）以及GT×RGB预测×融合预测；由此算P(D正确|R错误)、P(D错误|R正确)、both-wrong与真实融合救回/损伤。补救容量不等于融合收益，correctness差也不等于mIoU差。

**部署主动作**为0.9p_R+0.1p_D概率融合，无目标调参。固定敏感性权重α∈{0,0.05,0.10,0.20,0.40,0.60,1}全部报告，p=(1−α)p_R+αp_D；固定0.9/0.1 logit融合为尺度敏感性参考，不挑最好的一条替换主动作。保存α∈{0.05,0.10,0.20}的平均净增益，仅作预设动作范围摘要，不称已选出的部署策略。

概率融合有可翻转上限：当RGB错误最高类与真类概率差>α/(1−α)，即使DSM把真类概率置1也不能纠正；α=.1的上限为1/9。保存错误margin≤1/9与>1/9分层及各α潜在可翻转支持。主动作失败只否定该动作契约下的收益；不能据此将新增信息判为无用。

三个RGB种子与三个DSM种子在同fold做完整3×3换配。同seed配对为主，不同seed的6种配对是固定迁移诊断，不新增模型，不反选最好RGB搭档。教师和部署R的困难分布也完整列出。

校准报告包含固定15等宽bin的ECE/NLL与概率幅度；按允许样本统计、不用其调温度。训练轨迹记录loss、更新范数、权重分布、梯度/激活摘要和有限值检查。诊断图只输出预先固定位置，不能只挑正例。

## 8. 预登记的推进与停止规则

下面是新问题的实用推进规则，不是统计显著性标准，也不修改Phase2.4/M1原门禁。所有数值均为百分点；“相当”只表示没有达到预设实用增量，不宣称统计等效。

- G0工程：108作业端点、数据/teacher绑定、配对样本流、主CM与联合边际可核验。缺失时结果标不完整，不静默删除失败臂计算赢家。
- G1对应性：RGB-down4上，DF相对D0、DSelf、DShuffle、DEntropy的DSM补救率，三seed平均增量分别至少+0.5；每个seed池化增量都>0。DF−DClean在all与damaged分别至少+0.3且三seed都>0，才支持退化条件特异性；H1/G1与H2分开登记。未达到后者时仍可讨论一般困难对应性，但不扩展“退化特异”路线。
- G2兑现：主α=.1下DF相对D0的融合mIoU三seed平均≥+0.3、每seed>0；相对DSelf/DShuffle/DEntropy/DMix/DClean各自平均≥+0.2、每seed>0。9个fold×seed的DF−D0至少7个为正。若DMix同样解释收益，保留简单融合目标，关闭专门重加权新方法主张。
- G3保护：DF相对D0，clean和RGB-down4 healthy区域的每seed池化差均≥−0.2；每个外层tile的三seed均值≥−0.5；DSM-down4及平移面板每seed池化≥−0.2。不能拿平均收益掩盖某个tile的明显损伤；完整列出比原门禁更严格/更宽松的具体项，不冒称通过旧联合保护门禁。
- G4迁移：不同RGB seed的6种换配中至少5种，其12tile池化DF−D0主融合增量>0；三个未见RGB退化面板各自三seed平均>0，且各seed不低于−0.2。仅已见退化有效则关闭未知退化推广主张。

仅G0–G4均满足才派发下一节反向训练；第二编码器阶段还需其依赖和源代码冻结。若H1/H2被普通控制解释，结束这套配方，不自动改λ、alpha、seed、训练长度或添加新的门控。

如果G1通过、G2失败，保留“补救信息改变但当前动作未兑现”的结论及margin曲线；本计划不自动派发新融合头。如果G2通过但G1不成立，保留性能结果，不声称错误对应性机制。部分seed反转要解释为不稳定，而非完全无作用。

不对像素/mask数做独立样本t检验。三个fold训练池互相重叠，三seed及12tile仍不足以支持独立城市显著性。报告配对效应、方向一致性和每tile范围；任何重采样区间必须标为同城开发集敏感性，不能当外部确认。所有对照固定32k，不用事后准确率配平或挑不同训练年龄宣称因果。
