# D22 草案：RGB 锚定的细尺度 DSM 结构对齐

**状态：研究设计草案，代码与冻结配置尚未完成，服务器不得据此直接排训练队列。** 本草案把 D21 的两条证据变成可证伪问题：正确空间配对的高频分量有小幅正向信号；DSM 缺失与 Vaihingen 局部负迁移仍未解决。不得把该设计或未来结果倒写为原论文已实现贡献。

## 假设与区别

固定 D21 同数据集 seed42 的 R0 光学模型作为主路径，只训练1/4尺度 DSM 特征残差。若 DSM 整幅为精确零，则在残差加法前将残差乘零，使输出与该 R0 checkpoint **逐像素相同**；这是工程安全不变量，不算学会了可靠性。候选进一步用 RGB 与 DSM 高频边缘的局部方向一致性调节高频残差，检验它能否在保留完整 DSM 收益的同时减少错位与局部受损时的负迁移。

这与已失败的 D13 冻结 RGB 分类输出残差和风险损失不同：本草案位于 D21 的1/4尺度空间特征层，研究明确的频率空间对应，采用位置打乱对照；不使用 D13 的风险目标或其旧 Val2 门槛。D13 的失败仍作为限制报告，不能据此预期成功。

## 匹配设置

每个数据集使用既有 D21 R0 seed42 最终 checkpoint 作为唯一锚点，先核对 SHA、训练步数、split 和 `test6_loaded=false`。Potsdam 只用 Train16/Val2，Vaihingen 只用12训练块/17开发块；两数据集各一个 seed42。不新增数据、权重或环境下载。四个待训练设置均冻结光学主路径、使用同宽同参数量的 DSM 残差头、同一训练样本键、退化概率、优化器、16k 更新和评价条件。原 R0 只重做绑定后的开发评价，不重训。

| 设置 | DSM 残差输入/处理 | 要回答的问题 |
|---|---|---|
| A1 | 1/4尺度 raw + 零通道 | 细尺度高度与相同残差容量的基线 |
| A2 | D21 的低频 + 高频，未门控 | 高频分解本身的收益 |
| A3 候选 | 低频 + 高频×边缘方向一致性门 | 正确空间对应能否选择性减少负迁移 |
| A4 | 低频 + 高频×空间滚动后的 A3 门 | 门值分布相近、但位置对应被破坏的对照 |

门在1/4尺度计算：RGB 灰度与 DSM 高频各经固定 Sobel 梯度，取两梯度夹角余弦的绝对值并截到 `[0,1]`；分母固定 `ε=1e−6`。A4 将 A3 的门沿高、宽各循环平移半幅，不改变门值直方图。门没有可训练参数，不输入真值、区域 ID 或退化条件标签。所有设置在残差末端使用相同的整幅 DSM 零值掩码和相同的零初始化输出层；A1/A2/A4 也有同样的缺失回退，不让 A3 因独享安全机制获益。

## 事前检查与判定

先做 CPU/单卡短流程：输入、输出、参数量和冻结参数核对；原 R0 与四设置在 `aux_zero` 时的 logits 逐元素相等；`aux_local_zero_q1` 仍应产生有效、有限输出；随机种子和样本键在四设置之间一致。暂以有效 batch16 的 `16×1` 运行短稳定性与梯度检查；若不通过，四设置一同回退到 `8×2`。先测新头实际吞吐，再给正式队列估时。短流程不是准确率结果。

候选 A3 事前开发门槛：在 Potsdam 和 Vaihingen 各自的 seed42 主尺度上，相对 A1/A2/A4 中最强综合分至少高 `+0.2 pp`；clean 不低于最强对照 `0.1 pp`，光学质量和辅助质量家族各不低于 `0.3 pp`；逐 tile clean 与家族保护沿用 D21 的 `0.1/0.3 pp`，失败区域完整报告。`aux_zero` 与 R0 的像素级相等是实现门禁；`aux_local_zero_q1` 另与 R0 和 A2 做逐 tile 诊断。前五类边界 F1、类别 IoU 和伤害/救援计数作为诊断，不替代准确率及 tile 门槛。
