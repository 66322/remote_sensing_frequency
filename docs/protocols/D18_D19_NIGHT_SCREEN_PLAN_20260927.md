# D18/D19 单seed多方案夜间初筛计划

状态：**重写版建议；尚未实现为可执行队列，未启动服务器任务。**
2026-09-27用户要求多安排方案，只对后续值得复验的实验增加seed，并把评估接在训练后。
本计划取代上一版默认三配置同时跑seed42/17的安排：本批所有训练仅seed42，
不自动追加seed17。采用实验设计原则分组匹配对照，避免结构、损失、参数量一起改变后无法归因。

## 范围及依据

[D16/D17审计](../experiments/D16_D17_RESULTS_20260927.md)已完成，A2和B1关闭。
本批保留原计划的预训练表示与适配器对照，以及
[ISFuse迁移六配置框架](ISFUSE_TRANSFER_REVIEW_20260926.md)中的结构问题，
但任务条件约束由必跑改为条件触发，并补上容量对照。
目标为8项基础训练、最多2项条件训练；必要推理诊断另计，不当作新训练数量。
所有结论为探索性筛选，反复使用Val2和单seed不能支持确认性论文结论。

## D18：同一预训练表示下的模态价值（三项基础任务）

选择一个权重可获取、许可清楚、能在服务器独立环境运行的预训练视觉骨干；
不同时测试多个骨干。具体型号与权重SHA在实现及权重可用性检查后冻结，
未完成该项不得把本计划标为可启动。冻结骨干，训练相同解码器和轻量适配器。

| 编号 | 输入与结构 | 对照目的 |
|---|---|---|
|P0|RGB，单路适配器/分割头|新表示下的RGB基线|
|P1|RGB＋灰度辅助，双路适配器|额外容量与重复视觉信息对照|
|P2|RGB＋DSM辅助，与P1相同结构|DSM是否带来独立于容量的收益|

P1/P2辅助编码器、参数量、初始化规则和计算预算保持一致，仅辅助输入含义变化。
不能简单把原始高度复制为三通道并认为已经获得匹配的视觉预训练；辅助输入编码、
归一化与适配位置必须明确，并对P1/P2一致执行。
采用共同的主任务增强与模态退化分布；P1的辅助退化作用于灰度，须如实命名。
暂定每项8000步、固定最终权重、有效batch16；学习率/输入尺度由可用模型确定，
在首个正式任务前整组冻结。P0/P1/P2使用相同训练样本与处理随机序列。
若吞吐不合预算，可在正式启动前整体改为更小预算；不得根据结果给赢家额外训练。

本组从同一通用预训练起点建立新分割头；与旧R05继续训练的D19不做预算等价主张。
P2只超过旧R01，不构成DSM独立增益证据；必须比较P0和P1。

## D19：结构化干预与融合结构（五项基础、两项条件任务）

所有基础项从同一seed42 R05归档权重开始，统一继续4000步、固定最终权重。
使用同一结构化局部遮挡分布、裁剪序列、优化预算、两视图分割监督。
改变遮挡分布后，旧D16 A0不能替代本组C0；保留旧结果仅供背景比较。

| 编号 | 融合/目标 | 目的与启动条件 |
|---|---|---|
|C0|现有融合＋结构化干预＋分割监督|本组匹配增强基线；必跑|
|C1|C0＋普通输出一致性|测普通一致性收益；必跑|
|C2|一个固定的CFI启发融合插入＋分割监督|测结构变化；必跑|
|C3|C2＋普通输出一致性|测结构与一般一致性的组合；必跑|
|CP|常规局部融合/残差适配模块＋分割监督|匹配C2新增容量，排除仅多参数；必跑|
|C4|C2＋任务条件一致性|仅在结构门槛通过后运行|
|C5|C4的类别/数量匹配打乱任务权重|与C4成对运行，不单独保留赢家|

CFI启发插入仅一个固定位置/规模，不做多位置搜索，不把分割适配称为原图像融合复现。
CP新增可训练参数目标与C2相差不超过5%，同时报告实际FLOPs；若计算量不同，
不能将其称为严格计算匹配。系数与mask参数须在正式运行前写入配置。
不复制原文存在解释歧义的必要性损失，也不使用图像融合的强度保真损失。
两种输入同时缺失的位置单列，不能强迫不具备证据的局部表示保持一致。

结构触发门槛：C2相对C0与CP中较强者综合分数至少+0.2pp，或
C3相对C1与CP中较强者至少+0.2pp；同时满足下述clean/逐tile保护条件。
这仅支持增加诊断预算，C3路径尚不能排除容量与一致性的交互作用，不自动建立创新结论。
若通过则运行C4和C5；未通过则标记SKIPPED，并继续其它独立任务。
C4仍需超过C3与C5，不能因结构分支通过就认定D16失败的任务约束获得支持。

## 所有训练都带自动评估和验证

每项任务是：训练 → 保存最终权重与绑定 → 重载 → clean确定性复算 →
全图9条件评估 → 新扰动推理 → 逐类/逐tile与harm/rescue → 原子写入摘要。
任何阶段失败不得写COMPLETE；权重存在也不能当作评估完成。

- 标准条件沿用clean、4项RGB质量、2项辅助质量、2项已知缺失，Potsdam Val2。
- 增加两个训练未用的固定诊断：RGB对比度0.6（训练归一化前围绕0.5调整），
  DSM向右平移8像素（边缘复制填充）；P1对应移动灰度辅助，P0输出应不受辅助变更影响。
  在启动前核对训练分布确实未包含这两项，不事后添加难度来挽救候选。
- 新扰动仅作单列诊断，不改变已冻结主综合分数；Test6不加载。
- 同时保存FullGT与NoBoundary的int64 6×6混淆矩阵、逐类计数、tile结果、权重/源码/config SHA。
- 保存必要预测掩码用于边界诊断；已有D16 A0/A2/B1/B2可复用权重做seed42推理诊断，
  不重训。边界容差固定为原图3像素、忽略无效标签邻域，使用FullGT，记录完整定义。
  不能把边界像素数量当作独立重复数，亦不能据此推翻D16/D17已失败的主门槛。
- 缺失模态下的原模型输出与显式回退结果分别报告，不把回退收益当作学得的鲁棒性。

## 双GPU有限队列与故障处理

1. 权重/数据/输入通道/数值检查和各独特结构的训练-保存-重载-评估短流程先行。
   预训练权重下载失败只阻塞D18，已通过检查的D19可独立继续，避免两卡一起空等。
2. GPU0/1共享就绪任务队列，每项训练后优先完成其评估；释放卡后领取下一项。
   不固定GPU0专门训练、GPU1串行评估，不把GPU型号/卡号与方法永久绑定。
3. 建议先P0与C0，再P1/P2和C2/CP/C1/C3；具体就绪调度按依赖与空闲卡推进，
   CP/C0/C1未评估前不判断C4/C5触发。推理诊断可填充短空档。
4. 独立任务失败记FAILED并继续其它任务；有依赖的任务记BLOCKED，不伪装成方法失败。
   不自动重试同一个确定性代码错误。最终汇总显示完整数、失败数、阻塞数及条件跳过原因。
5. 启动前记录预计步时、评估时长与显存。24小时仅写进度，不终止已授权的有限队列。
   断点续跑校验配置/源码/权重绑定，恢复优化器、调度器与随机状态，避免从头再算。

## 初筛与后续复验

主分数沿用clean/RGB质量/辅助质量三组等权；组内平均。
候选相对最强匹配对照至少+0.2pp；clean整体与每tile下降不超过0.1pp，
任一条件组整体/每tile下降不超过0.3pp。主表必须显示所有基础任务，包括失败候选。
harm减少的主张还需rescue至少保留匹配对照的90%；单seed通过只记候选。
今晚不自动运行seed17，复盘后对有信号的方法和必要对照一起补seed，不能只复验赢家。
即使两个seed通过，仍需独立场景才能建立更强泛化证据。

## 时间与交付边界

旧4000步双视图任务实测约3.6–3.9小时/项，评估约10分钟。
以该速度作参照，D19五项基础训练已约18–20 GPU小时；新增结构可能更慢。
D18新骨干与随机分割头的训练成本尚未测量，不能把冻结骨干自动等同于很快。
完整批次应按可能跨过一天安排；预计总墙钟由全部任务训练/评估GPU小时除以2，
再计依赖、加载与最后一个任务造成的空隙，完成短流程后再给数值估计。
