## 2. 研究角色与优先级调整

主线仍为RGB–DSM条件互补与退化/缺失分割，恢复仍旁支。建议本轮优先研究：
“局部像素缺失时，周围上下文形成的特征还可不可以用？正确的缺失信息是否被过度用于删除特征与输出？”
这是缺失数据处理×空间上下文×多模态决策的交叉问题。它允许最终证据只支持一个方向，不为标题强迫双向创新。

顺序从原来的E3/边界→N3，调整为：
1. E3与N5后边界CPU复查，同时准备E4-v2三处操作分解；
2. 若输出回退问题成立，R1四组优先；
3. 若只有内部特征删除问题成立，转S1四组，R1不硬跑；
4. N3五组保留为区域归属问题的匹配检验，依旧需要N5-0与N5-3边界复查通过；
5. 本窗口最多两个训练族、最多9个新8000步作业。另族留作储备，不把13项全部启动。

调整理由是E2差值约1pp且可直接干预；N2/N5结构与暴露增量失败之后，应先解释现有处理链的损失。来源是用户允许换交叉问题与已验收证据，不是主线已正式变更或新机制已成立。

## 3. 先做诊断，0次optimizer更新

### E3：类别/边界构成与N5后空间问题
复用A0/B1原E1以及N5-0/N5-3已保存预测；必要时纳入另外两N5作描述，不能改主候选。
- 同面积U/H/L遮挡，按fg5类别×Full 4px边界/内部交叉统计；每层支持至少100像素，所有比较使用共同支持层。
- 按同一tile完整有效区域的类别×边界频率固定权重，报告标准化正确率、原始CM/mIoU和未覆盖质量；不能称“校正后的mIoU”或纯因果效应。
- 不从全局CM反推分层；标签只用于事后评价，不参与缺失位置/前向。
- 对N5-0/N5-3各自两Val tile，严格复用原E0 Full/4px边界、锚点正确并集harm分母与min100支持、单侧正确支持规则。两模型各两tile都达到边界−内部≥1pp，才保留N3训练优先级。
- E3若明显削弱H压力，转向“对象/边界构成差异”的解释；不通过标签重选遮挡来挽救N5。

### E4-v2：输入清零A × 特征删除B × 输出回退C，8条推理路径
源码依据：[N1实际前向](../../model/rebuild_v1_post_ab_n1.py)包含输入masked_fill、pyramid各尺度和merge后的valid_at相乘、最终torch.where三个位置。原E4 2×2不足以完整分离B；本次新增B作为显式因素。N2适配路径还须在实现时完整追踪，不能照抄N1后声称隔离完成。

固定模型N1-2、N2-0；N2-3只作预先列出的旁证。输入使用原U25%固定掩码；RGB/DSM分别受损；每侧“物理零块+正确报告”和“完整物理输入+同位置误报”两种状态，Val2两个tile。
- A=1依报告清零；A=0保留接收到的物理输入，绝不恢复原始被遮像素。
- B=1按原路径删除特征；B=0保留编码器从受损输入形成的上下文特征，不恢复任何遮前特征。所有相关feature/donor mask路径显式记录；报告mask仍是已知输入，不能改成全True。
- C=1原局部硬回退；C=0局部保留raw融合输出。全模态缺失和两侧全无效的安全规则另行保留与测试，不能因实验开关删除。
- 一共8×3×2×2×2=192个模型路径×方向×物理状态×tile单元；这不是192组训练。可以严格绑定复用原路径，但不能提前承诺节省。
- 分别保存expert输入hash、特征掩码、回退前logits/后logits绑定与CM，证明改变了哪个路径。相同zero输入下A开关本应一致，这是必要工程负控制；误报状态下A才改变物理输入。
- 输出回退问题筛选：固定A=1、B=1，C=0对C=1在真实RGB U缺失上，N1-2和N2-0各pooled fg5≥+0.5pp且各两tile正。只有此门槛过才进入R1；DSM全量报告，不事后替换触发方向。
- 特征删除问题筛选：固定A=1、C=0，B=0对B=1在真实RGB U缺失上，同两模型各≥+0.5pp、两tile正，才进入S1。它与输出门槛独立；N2-3不替换失败主模型。
- 报告A/B/C主效应和交互的描述性差值；不以任意最优8路径取代固定比较。上述新门槛不重判原E2。

为什么不把预测联合上限当作收益保证：锚点oracle只能说明存在可救像素，不意味着在无标签输入下可识别。此次要用可实现且不读遮前内容的推理操作检验。

## 7. 文献启发及边界（2026-10-06核对原始摘要/官方页面）

- [Liao等：Benchmarking Multi-modal Semantic Segmentation under Sensor Failures](https://arxiv.org/abs/2503.18445)，CVPR2025 Workshop。区分整模态缺失、随机缺失和噪声，本项目进一步拆开物理观测、报告标记与模型内部处理。论文不证明本项目的R1/S1有效，合成U不等于真实传感器故障。
- [Liu等：Image Inpainting for Irregular Holes Using Partial Convolutions](https://arxiv.org/abs/1804.07723)，ECCV2018。有效像素条件计算与逐层mask更新说明输入缺失和后续特征支持可以区别处理；这里只借鉴问题视角，不主张其inpainting结论直接适用分割，也不宣称S1使用了其算子。
- [Mei等：SPFormer](https://arxiv.org/abs/2401.02931)，2024。内容自适应超像素表示启发N3；是否超过同容量网格必须本地验证。
- [Yin等：DFormerv2](https://arxiv.org/abs/2504.04701)，CVPR2025。深度/空间几何先验启发条件归属；遥感DSM不直接等于相机深度，且本项目N2已失败，不能把文献成功当作扩大N2预算理由。
- [Peng等：Balanced Multimodal Learning via On-the-fly Gradient Modulation](https://arxiv.org/abs/2203.15332)，CVPR2022。模态优化不平衡是一种可能，但现有D25与N5证据不足以证明它是当前瓶颈；N4不因此自动启动。

此次为针对性问题检索与摘要级来源核验，不是系统综述或新颖性排他证明。拟投稿前仍需近邻方法与完整实现对照。

## 9. 去留判断：何时真正换方向

1. 输出或特征处理的简单控制已经恢复主要损失：将研究重心转为“局部观测与空间上下文的可靠利用”，先建立简洁强基线；不能仅把取消开关写成充分创新。
2. N3超过局部和网格且方向成立：继续结构/区域问题，后续再研究机制边界与独立验证。
3. E4各固定对比不成立、N3匹配增量也失败：暂停在当前基座上继续做新门控、传播、蒸馏和内容缺失增强，不能无限增加相似配置。
4. 更远方向可转“分辨率变化×几何边界的任务驱动恢复”，但须先做退化相同的双线性/普通分割/SR监督/联合任务四格设计与旧D21/Post-D21失败配方差异审查。当前只作下一轮问题候选，不在本窗口追加恢复训练、不把旧失败SR改名重跑。
5. N4仍需真实条件参数更新暴露，静态梯度/像素计数不够；R2因N5失败保持不激活；E5形状迁移只作边界诊断，不救旧gate。

当前证据来自持续开发的两Val tile和seed42，差值门槛是工程/研究筛选标准，不是显著性检验。重复使用Val2存在适应风险；像素、窗口、条件和不同模型都不是独立训练重复。此轮目标是在有限预算内判定哪个问题值得继续，不承诺必有正结果或最终论文贡献。
