# 下一轮配对训练：可靠性互补可行性草案（2026-10-13）

状态：**助手建议 / PLANNED_NOT_IMPLEMENTED_NOT_REGISTERED**。本次没有新训练、种子、queue或服务器操作。结果依据[Phase1.5完整分析](../experiments/PHASE_1_5_RESULTS_20261013.md)。本草案不宣告原routing门禁通过，不追认已上传模型为配对专家。

## 唯一问题与阶段去留

研究问题：在专家架构、训练数据和预算受控后，部署时可取得的可靠性信号，能否比强静态融合稳定改善RGB–DSM双向退化/缺失分割？

先做2个匹配单模态专家，检验训练来源混杂；再决定是否进入4个融合头的受控可行性阶段。五专家真值oracle不是方法、目标或收益保证；不并行开展恢复损失、频域解码、边界修复等另一条路线。若没有匹配专家互补空间或动态头不能超过控制，结束本路线可行性阶段，不自动追加种子、续训或替换配方。

## 阶段A：2个匹配专家，32k更新

A_RGB / A_DSM各16000 optimizer updates、seed42，同一Potsdam fit12、同一公共DINOv2-S/14单模态分割执行图、公共预训练encoder及同一随机decoder初始化。采用现有optical-only执行链作为实现基底，但必须以新独立入口锁定实际可训练参数及初始化哈希；不载入旧RGB/DSM的分割checkpoint。DSM归一化沿既有可审计定义，单通道复制三通道进入同一图；不引入DSM专用几何模块。RGB与DSM输入统计差异保留为模态因素，不能保证同等实际精度。

两者使用相同fit12裁剪ID、标签、空间增强与batch序列，batch16（实际更新而非累积），同步训练预算、验证频率和选模口径；第一阶段使用clean各自模态、仅分割CE。RGB独有颜色增强禁用，避免增强历史成为额外混杂。学习率、参数组、冻结层和调度须在执行包中给出唯一公共数值配置，并在启动前锁定，不能分别为两模态调参。此处未实现配置锁定，因此不提供可执行命令。

GPU0=A_RGB、GPU1=A_DSM同时跑；保存4000/8000/12000/16000轨迹、公共best规则和endpoint。用validation pooled fg5(full)选checkpoint；全程保存int64 CM、逐类计数、逐tile和来源SHA。选择后的专家冻结，不再随头联合适配。

阶段A只进行一次技术/互补审查：在预先冻结的双向退化/缺失面板上比较两个专家及静态混合，离线joint-correct coverage仅作诊断。若源绑定不完整、某专家技术失败或不同步，不进入B，也不自动重试；若只能靠某一专家单边支配、未见两方向互补，不自动派发全部动态头。互补阈值需在执行配置生成前明确，不能用测试集或结果后改门槛。没有外部来源通过也可做该开发可行性检验，不能声称独立泛化。

## 阶段B：最多4个融合头，32k更新

每臂8000更新、seed42，共用阶段A冻结checkpoint、相同crop/退化/availability序列、初始头状态、优化器和CE；不更新专家。预测级凸组合后采用一致的分割损失，已报告availability负责不可用专家屏蔽。

| 臂 | 变化 | 解释目的 |
|---|---|---|
| B0 静态融合 | 每方向学习固定混合偏置 | 可训练强静态参照；不是零训练规则 |
| B1 可观测动态 | 局部熵、概率差异、DSM均值/方差/梯度和已报告availability进入小MLP | 检验可靠性条件选择 |
| B2 信号消融 | 与B1同样MLP及参数量，将可靠性输入置固定常数，仅保留availability | 区分信号与头容量；B0参数量不同须披露 |
| B3 DSM统计打乱 | 与B1同图，将DSM统计图作预先锁定的空间打乱，专家预测与mask不动 | 检验DSM空间可靠性对应，不是打乱DSM专家输入 |

B1/B2/B3完全相同MLP；具体通道、邻域、打乱索引和loss缩放在实现时冻结。B2可能退化为静态行为，不能把相同函数空间包装成额外独立证据。熵等信号只能从当前输入/冻结输出计算，不能用真值、实际错误图、GT边界、condition标签或oracle专家标签作为部署输入。训练GT仅用于分割CE；真实未报告故障不向模型泄漏合成mask。已知missing与未报告degradation分开报告，不把known-mask成绩当盲故障识别成绩。

对称训练面板至少含clean、RGB局部missing、DSM局部missing、各自退化以及双模态局部缺失；同一batch各臂共享物理输入与可用性。具体比例/损坏强度、顺序必须启动前注册；pixel与块状各占同权，不根据本轮表现抛弃pixel。验证复用冻结的缺失几何/剂量与既有普通退化，并加镜像DSM缺失；训练/验证随机流分离。评估清楚区分完整区域、缺失ROI、healthy ROI与共同支持，避免重复B中的面积混杂。

GPU排程：第一组B0 GPU0 / B1 GPU1；第二组B3 GPU0 / B2 GPU1。每个臂单卡，跨GPU记录batch_hash和精度模式；这里只有seed42，不把两卡当重复试验。阶段B不因A结束自动启动，需先落地完整协议和A审查回执。这里的条件审核是尚未确定的科学步骤，不是额外用户权限要求。

## 验证与预定判定

主读数为双向面板等权的pooled fg5(full)，附完整CM、逐类/逐tile、clean与worst-condition、missing和healthy ROI。不能仅选收益最大的几何。主要比较B1−B0及B1−B2，B1−B3检验DSM空间对应；报告两tile每条件差和20既定mask配对均值/CI，后者不当独立泛化置信度。

建议启动前冻结的开发门槛：B1比B0和B2的双向总均值均≥0.5pp、两tile均正；clean相对B0不低于−0.3pp，任一方向总均值不负，worst-condition不低于−0.5pp。这些是新可行性预算门槛，不是文献阈值或从oracle倒推的预期收益，必须在执行包注册前确认其定义及权重；未达时完整报告并停止扩展。B1−B3若不稳定，不声称DSM空间可靠性机制成立，即使总均值过门槛。

阶段A与B不同时选模优化；完整轨迹区分训练损失、clean验证和退化验证。新匹配模型与旧S1/S13/R16只作背景参照，不把更换初始化/骨干后的差分当一个模块消融。全部只属开发Val2单seed阶段，确认性多种子和独立泛化另行规划，当前不增加。
