# 从文献思想到实验的持续规则

生效2026-10-01；来源：用户要求开展实验参考最新论文、可借鉴他人思想。

每次提出实质新科学实验，应在启动前写清：当前证据中的未决问题；最接近的近期原论文；借鉴的具体思想及模块/目标；我们的差异与可证伪假设；必要的匹配对照和消融；评价口径、预算及去留条件。只修复调度或查询进度，不重新走文献流程。

使用出版方、作者原文及官方实现核对；明确已发表、Workshop和预印本，标记仅摘要/方法节/全文/代码局部/已复现的真实范围。论文的新日期和他人的正结果不自动赋予适用性或创新性。原作者的损失、原型、门控和缺失增强均应有来源；组合或名称变化不等于贡献。对领域/通道/split/骨干/训练预算/指标不同的分数，不作直接排行榜比较。

已有定向记录见[2025—2026候选文献与实验映射](../literature/RECENT_MULTIMODAL_SEGMENTATION_20261001.md)。新对话直接复用，仅在提出新假设、出现相关新论文或资料缺口影响判断时补查；不为每次接续重复检索、资源审计或预算探针。文献准备与既定训练可并行进行，不将全面综述作为所有工作的新门禁。

最终方案、近邻差异及代码来源写回GitHub同一研究分支，更新当前决策和下一步，区分用户要求与助手候选建议。借鉴思想并不意味着已采纳新路线、已批准所有候选长训练或已验证论文贡献。科学实验的原有执行和数据规则继续生效。
