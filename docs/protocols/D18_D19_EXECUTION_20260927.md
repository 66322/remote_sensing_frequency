## 固定内容

- 全部seed42；8项基础训练，最多2项条件训练。没有seed17自动复验。
- D18 P0/P1/P2：DINOv2 ViT-S/14，官方代码commit
  `7764ea0f912e53c92e82eb78a2a1631e92725fc8`，官方HTTPS权重。
  [来源与接口](https://github.com/facebookresearch/dinov2)、
  [该版本模型卡/Apache-2.0许可](https://github.com/facebookresearch/dinov2/blob/7764ea0f912e53c92e82eb78a2a1631e92725fc8/MODEL_CARD.md)。
  权重下载后记录大小和SHA；该SHA为实测绑定，不冒充上游公布的校验值。
- 骨干冻结且保持eval，RGB按ImageNet均值/方差归一化；512输入补边到518，
  产生37×37的14像素patch特征。RGB投影128通道，轻量分割头在1/4空间网格工作。
  灰度/DSM按相同14×14区域池化，再经1→32→128辅助适配器，保持几何对应。
  不声称DSM编码器获得视觉预训练；P1/P2的结构与初始化匹配。
  固定8000步，有效batch16，AdamW学习率3e-4，warmup100步后poly衰减。
- D19 C0/C1/C2/C3/CP：共同R05 seed42 16k权重起点，继续4000步；
  微batch2、累积8，旧骨干2e-5、解码头倍数10，一致性0.2。
  旧退化采样外，以0.5概率选择RGB局部遮挡、辅助局部遮挡或互补遮挡，单块面积1/4。
- C2/C3/C4/C5仅在第一个SE融合位置增加窗口8×8、q/k16维、value32维的局部交互残差。
  残差系数从0开始，初始输出精确保留旧模型行为。CP采用普通局部卷积门控残差。
  新增参数C2为10,401、CP为10,369（约0.31%差距）。两者计算并不严格匹配；
  保存额外卷积/注意力MAC估计，不宣称全网络实测FLOPs或推理加速。
- C4/C5的任务约束/打乱对照只有C2或C3通过已固定结构收益与保护门槛后运行。
  CP没有普通一致性损失，C3通过仅触发进一步诊断，不自动证明结构相对于容量的独立贡献。

实际配置：`configs/rebuild_v1/d18_d19_night_20260927.json`。新骨干组与旧权重继续训练组
各自做组内匹配比较，不将不同起点/预算的横向分数解释为机制增量。

## 自动闭环及输出

每项训练保存优化器、调度进度、Python/NumPy/Torch/CUDA随机状态和数据处理绑定。
随后保存训练tile上的clean探针；评估重载最终权重并要求探针预测精确一致。
再执行Val2全图clean、4 RGB质量、2辅助质量、2缺失条件，及固定contrast0.6/shift8诊断。
smoke也走完整保存/重载和三个推理条件，不只检查一次前向。

保存FullGT/NoBoundary混淆矩阵、逐类IoU、tile结果、harm/rescue、缺失区域回退结果。
各条件预测掩码存为服务器npz，边界计数使用FullGT、五前景类、Chebyshev半径3；
排除无效标签邻域，不使用NoBoundary去支持边界改善结论。
P0额外检查辅助变更下原始混淆矩阵不变。

队列自动复用D16 A0/A2/B1/B2 seed42已完成权重，运行clean/contrast/shift边界诊断；
不重新训练它们，也不改变D16/D17原筛选结论。

路径：
- 训练：`runs/rebuild_v1/D18_D19_{arm}_seed42_{steps}_20260927/`
- 评估：`records/rebuild_v1_d18_d19_20260927/{arm}_seed42/`
- 旧权重诊断：同评估目录下`LEGACY_{arm}_seed42/`
- 队列：`records/rebuild_v1_d18_d19_queue_20260927/`
- 判断：`records/rebuild_v1_d18_d19_20260927/decision.json`

结束后按 [GitHub跨电脑归档要求](EXPERIMENT_GITHUB_HANDOFF.md) 提交完整的紧凑证据：
队列状态、条件筛选与最终decision、每个已评估组的summary、逐条件/逐类/逐tile
指标及原始计数、与匹配对照的差值、失败和跳过原因、运行版本及检查点路径/校验值，
并更新实验报告、状态和下一步。仅记录服务器路径与SHA不足以判断实验效果。
