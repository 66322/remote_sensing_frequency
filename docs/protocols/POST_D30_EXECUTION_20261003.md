# Post-D30执行协议：18主体＋4条件组

决策来源：用户明确要求根据D30结果实施既有12＋4计划，并允许增加若干组、实验时间充足。本协议实现并扩展[原12＋4计划](POST_D30_PORTFOLIO_20261003.md)；原D27/D28/D30阈值保持不变。研究仍是RGB/DSM双向条件互补与任一侧退化/缺失下的可靠分割。没有新贡献确认；不是多seed验证。

| 阶段 | 组别 | 目的 |
|---|---|---|
| A，6新训练 | A0无对齐、A1全128维对齐、A2共享64维对齐、A3错配共享对齐；A4/A5为共享权重0.03/0.3 | 区分对齐范围及强度。固定主候选A2权重0.1，敏感性结果不替换它的gate |
| B，6新训练 | B1仅小错位增强、B2仅5×5对应、B3二者、B4错配对应；B5/B6为3×3/7×7对应＋增强；B0复用A0 | 区分普通增强与对应修正，比较搜索范围，不选择最佳范围事后救gate |
| C，6新训练 | C0单侧任务CE、C1普通KL、C2教师正确mask KL、C3同mask额外硬CE；C4/C5仅给剩余RGB/DSM蒸馏 | 两侧学生都训练；分别验证两种缺失。单向组每方向权重与C2相同、总KD质量减半，只作方向诊断 |
| F，4条件训练 | F0空间polyphase、F1双侧Haar、F2不输入DSM高频、F3不输入RGB高频 | 只在固定B3 gate全部通过后执行；考察feature频率，不声称原始影像频段已分解 |

所有新组复用D25 P6 RGB锚点与D15 DSM锚点，fit12及开发Val2不变；seed42、8000步、物理batch16、一次更新两视图、不做梯度累积；4000/8000验证，三种完整/单侧clean均值选模、同分选早，fixed8000保留。A/B/F缺失位置精确回退自身冻结锚点；C学习缺失残差头，替代精确回退，不能继续声称缺失logits恒等。C完整输入沿冻结D26 B0 selected4000教师执行图，FP32评价应保持其完整输入结果。

A/B共有stride4、128维投影、64共享/64私有结构分区，两向128维预测器进入主任务CE，原私有特征旁路进入decoder；共享辅助分类CE总权重0.1全部A/B/F一致。全/共享对齐用normalized cosine，target stop-gradient，双方向均值、整体both-valid分母，总权重0.1。共享并非已识别的独立语义因素；错配固定空间roll只用于负对照。B只在共享特征上做无参数soft cosine局部搜索，温度0.1，外补位置剔除；私有旁路不被空间重排。对应mask是正常可用性，不接收真实位移/标签/质量ID。

为隔离新错位增强，**所有新组**的DSM质量候选统一为aux_down4/aux_noise_std010，移除历史aux_shift8；保留其余D26质量/可用性独立随机流。所有新组使用相同keyed crop，但裁剪坐标统一限制在能容纳DSM halo的范围；B训练0位移概率0.5，±2/±4原生方向各0.0625，DSM先从原tile邻域取样，再共同flip/resize，RGB与label位置固定。不向有效crop插入padding。该新流不能和D26/D30旧分数当作严格匹配新因果对照；A0是本轮匹配基线。

几何评价在完整原生tile施加dx8、dy8、二维sin形变8、形变8＋rgb_down4。sin周期512px、全tile原点相位0，inverse nearest采样，边缘clip，**评价统计只取8px内边界内的支持**；该支持mask只影响离线计数，绝不用于模型输入或切换路由。训练与评价尺度、插值和外缘策略显式记录；这些合成故障不是自然配准误差证据。原有10主条件、整图与局部缺失继续报告。边界诊断使用官方full有效且NoBoundary忽略的label集合，仅作离线评价；完整6×6 int64计数和逐类/逐tile/联合计数保留。

C的双向学生只接收可用模态，完整clean教师仅训练监督；teacher全部冻结。KL T=2、T²，总权重0.1，教师正确mask只由fit标签构成；归一化分母是全部可用且有标签像素。C3在同mask增加同权重硬CE；C0也计算相同教师输出以保留监督计算对照。两种缺失的clean及剩余模态质量条件分开汇总，不能用较强RGB掩盖DSM单侧无增量。C的训练额外学生前向较多，各组同预算但不宣称与A/B计算相等。

F沿固定B3结构/增强从相同seed重训8k，不叠加A2/C2。两个band block先pack，再非线性卷积，再unpack，参数和初始化四组相同；去HF在所有该模态feature旁路之前执行，避免原高频绕过干预，但允许模型从低频生成新输出。建筑/树木/车辆与full、label边界指标为诊断。
