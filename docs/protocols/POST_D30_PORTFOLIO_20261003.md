## 2. 公共设计

主体12组为A0—A3、B1—B4、C0—C3；B0复用A0作为2×2零点，不是新的第13组，也不是历史D26 B0。内部实现时使用D31_A*/D32_B*/D33_C*全名避免ID混淆。条件4组D34_F0—F3。所有新增训练先seed42，每组8000更新、物理batch16无累积；主体96000更新，条件32000更新。多种子不在此矩阵中。

固定D26使用的RGB D25 P6 selected2000及DSM D15 selected15000权重，不重训单模态锚点，不借旧held4作独立final。两锚点异构/预训练史不同，明确披露。所有组同fit12/Val2、裁剪、主质量/缺失随机流；模型专用扰动使用独立RNG，不改变裁剪或原增强序列。原先已看过的Val2结果仅作开发筛选，无像素级显著性检验。Test6不访问。

A/B基础采用冻结两锚点的分类前特征，沿D26已核对的stride4投影接口，128维划分为64维候选共享和64维候选私有。两类名称是结构约定，需用预测与干预支持，不能认定已解耦。私有特征保留在融合输入中；设置两个方向的128维预测器，其输出划分为相同64＋64；A1约束全部输出，A2/A3仅约束共享64维。原私有特征以独立旁路进入融合，预测器输出也参与共同任务CE；旁路存在不等于私有语义已被理论保证。所有A/B组模块、宽度、单模态辅助头相同，预测器参与共同CE前向，避免无损失组有未训练空壳容量。辅助CE两侧等权、总权重0.1，不做类别逆频率或D27protect/recover。最终接口与参数统计须在实现文档中绑定，若需改设计须在看新增结果前说明，不修改既有阈值。

A/B完整双模态主任务CE及训练视图继承D26，已知单侧缺失保持原锚点回退；没有新增缺失精度主张。C组单独改变缺失路径，见下文。A/B组4000/8000按原三状态NoBoundary pooled fg5均值选模，同分取早；C组同选模口径但缺失项现在可变化，故跨块不把选中步差异当机制。全组报告fixed8000及开销，不改变选模来救结果。

共同主报告：Potsdam Val2 3_11/5_10、native512/stride256、NoBoundary pooled fg5；旧C/QR/QD/QJ四族等权S_available及10条件逐tile/逐类、全幅/局部已知缺失、仅RGB/仅DSM正确保留、harm/rescue计数。保留full口径和原int64混淆矩阵/联合计数。新压力条件单列，不并入旧综合、不用于选模。

## 3. A组：对齐什么，比增加对齐强度更重要（4新训练，第一优先）

问题：保留私有路径，只对齐共享语义，能否减少“救回DSM却伤害RGB”的取舍？依据STARS/BiXFormer，但这是新的解释假设，不是已证明D27根因。

| 组 | 处理 | 要回答的问题 |
|---|---|---|
| A0 | 同容量共享/私有结构＋普通分割/辅助CE，无跨模态特征对齐 | 新结构和容量本身的对照；也作为B组零点 |
| A1 | A0＋两侧全部128维特征的双向预测对齐 | 全部信息被拉近的结果 |
| A2 | A0＋仅64维共享特征双向预测对齐，私有路径不承担此项 | 对齐范围是否决定收益伤害 |
| A3 | A2，但训练期对齐目标在每crop空间循环错配，幅度/数量/边际不变 | 收益是否来自真实对应，而非泛化正则 |

对齐拟采用每有效位置L2归一后cos距离，两方向平均、目标stop-gradient，合并权重0.1；只在双方有效的区域，按全有效像素均值，不稀有类别等权、不恢复区单独归一。所有组同任务监督，记录共享/私有方差、辅助分割与梯度，防止只降低距离却失去辨别力。全特征与子空间均按各自维度规范化；监督范围差异本来就是因素，不宣称梯度范数必然相同。A3仅扰乱辅助对齐目标，正常分割输入不打乱。

主比较A2−A0、A2−A1；A2−A3为对应性证据。若A2只比A1好但不超过A0，结论是避免有害对齐，不是新增融合收益。相较D25，这不是完整/缺失decoder分头或全局梯度投影；相较D26 XS，这不是用两锚点概率去调门控。

## 4. B组：修正局部对应，还是增强已经足够（4新训练＋复用A0）

依据GSCNet/IQSeg，检验跨模态信息位置不一致。所有组固定A0结构和普通CE，不带A2对齐损失，不选择上一组“最好模型”再叠加，确保因素清楚。

| 组 | 对应算子 | 新错位增强 |
|---|---|---|
| B0＝A0复用 | 同位置交换 | 无 |
| B1 | 同位置交换 | 有 |
| B2 | 共享特征局部soft correspondence | 无 |
| B3 | 共享特征局部soft correspondence | 有 |
| B4 | 与B3同算子，但空间错配对应权重 | 有 |

这是“对应算子×增强”的完整2×2，加一个错配对照。局部算子拟在stride4的5×5邻域内做两个方向归一相关匹配，覆盖约±8原生像素；私有路径不被强制对齐。普通组使用同投影、固定中心采样，避免额外参数解释收益；局部搜索计算成本另报。B4保留权重分布、网络和支持，打乱权重与查询位置关联；边界有效支持/实际作用数量须逐组记录。具体算子是可行性载体，不能称新配准方法。

训练增强只对DSM做0/±2/±4像素的无环绕平移（零位移概率1/2，其余八个轴向位移等分），在原质量增强之外用独立随机流生成；RGB与分割标签保持目标坐标。裁剪前带halo采样，人工越界边缘不当作有效观测。不能独立平移RGB却保留旧label，把错标签伪装成模态退化。两个信息方向仍参与交换，RGB质量退化沿旧QR条件完整评价。

评价固定四个几何条件：DSM(+8,0)、DSM(0,+8)、幅值8像素的平滑局部正弦形变、该形变＋RGB down4。局部形变令dx=8sin(2πy/512)、dy=8sin(2πx/512)，不提供形变真值给模型；位移支持/越界处理及tile固定相位在实施前写入plan，不能看结果后换强度。均不用于选模。加clean和旧条件，防止只改善特制错位。

关键比较B3−B1，而非只看B3−A0；并报(B3−B1)−(B2−A0)交互与B3−B4。若B1已经解释全部增益，保留增强结论、停止新算子。此处不同于D28“损坏支持是否共现”，不通过扩大原故障强度挽救D28。

## 5. C组：双向缺失补偿，能否超过直接训练剩余模态（4新训练）

依据STARS/EQUISeg的迁移思路，采用更小的任务蒸馏对照。当前冻结锚点回退已经能工作，研究的是缺失时精度能否提高，不再次从零训练RGB-only/DSM-only，也不声称能从RGB恢复不可观测的真实高度。

冻结D26 B0 selected4000为训练教师，冻结原RGB/DSM锚点。新增两侧轻量残差头，只读当前剩余模态特征；完整输入仍用冻结B0输出。C组相同结构/初始化、相同RGB-only和DSM-only监督。完整双模态教师只在训练时可用，推理不得计算或读取缺失输入。整体clean相同是接口设计，不能计为新clean贡献。全幅缺失采用已知可用性，未知质量检测不在C组范围。

| 组 | 剩余模态分割CE之外的训练项 | 对照意义 |
|---|---|---|
| C0 | 无 | 两残差头直接任务训练的匹配基线 |
| C1 | 双模态教师全部有效像素logit蒸馏 | 普通知识迁移基线 |
| C2 | 仅教师在训练标签上预测正确的位置蒸馏 | 避免传递教师错误，是否保留可迁移信息 |
| C3 | 与C2完全相同位置、相同系数，改为额外硬标签CE | 排除仅仅改变样本权重/监督量的解释 |

蒸馏拟用温度2、T² KL、系数0.1，两个方向平均；C2/C3均以所有有效像素为分母，非选中小区域单独均值，减少重演D27区域放大。教师使用同crop未施加学生质量退化的完整双模态视图，标签坐标一致；学生沿相同quality流生成剩余模态输入。教师correct mask只用fit训练标签、推理不输入；C3与C2同mask但目标不同，不能说梯度范数等价。全组固定同crop、每个训练样本两种剩余模态状态，教师前向预算相同；clean/aug视图一致，缓存只能复用精确输入/SHA匹配的冻结特征。两头梯度和实际有效像素分别记录，不假定覆盖即训练充分。

主报告分别给RGB-only、DSM-only，在clean与各自旧质量退化下的均值，不用二者总平均掩盖强弱模态代价。主比较C2−C0/C1/C3，另比固定原锚点；仅超过原锚点却不超过C0，只能归于额外任务适配。局部缺失若需要新边界处理，应另冻结扩展，不把全幅结果写成局部也成立。

## 6. 条件F组：频率究竟保留了什么（4新训练，当前不自动启动）

只有B3通过下面几何/安全门槛，才以固定B3算子为结构基础进入F组。理由是先证明位置修正有用，再比较两侧高频在位置已处理后的作用；不复活D26 XSF原确认路径，不自动把A2/C2与B3拼成大模型。

| 组 | 匹配输入表征干预 |
|---|---|
| F0 | 四相位空间打包，同维度卷积/混合，空间容量对照 |
| F1 | 两侧一层Haar低/高频全部保留 |
| F2 | F1，仅将DSM高频置零，保留RGB全频 |
| F3 | F1，仅将RGB高频置零，保留DSM全频 |

打包/逆变换之间有相同的卷积与非线性，避免Haar再立即逆变换成为恒等无效开关。四组通道宽度、下采样、可训练算子与解码器相同，不因置零削减参数。使用同B3增强；明确这是固定信息干预，不是加入未经验证的频率可靠性门控。WAMNet的DSM低频处理是参考，不预设DSM高频必然是噪声，也不预设RGB高频始终有益。

比较F1−F0确定频率表征是否超过空间载体；F1−F2/F3分别定位双方高频作用，按clean/错位、建筑/树木/车辆、FullGT边界带分开。边界带使用GT仅作评价分区，主NoBoundary及full同时保留；不能拿排除边界的主口径独自支持边界恢复主张。若仅F2较好，可形成该条件下抑制DSM高频的结果，不写成高频补偿贡献。

## 7. 预设开发去留标准（仅用于本次新计划）

下列是拟在实现前冻结的实用筛选，不是统计显著性阈值，不反改旧实验：
- A：A2对A0/A1的S_available均至少+0.2pp，对A3至少+0.1pp；clean对A0不低于−0.1、10主条件最差tile差不低于−0.2；双方独有正确保留各不低于A0−0.5pp，双侧harm分别按对应锚点正确但候选错误计数/锚点正确计数计算，两个方向均不增加（不是合并平均抵消）。fixed8000对A0增量同号。任一失败则不进入该机制确认。
- B：B3对B1四新几何条件均值至少+0.5pp，两tile各自该均值都正，对B4至少+0.2；clean对A0不低于−0.1，旧S对A0不低于−0.1，旧10条件最差tile差不低于−0.2，双方独有保留不低于B1−0.5pp。fixed8000几何增量同号。普通增强已足够则停止算子。
- C：双向补偿候选C2需对C0/C1/C3在每一种剩余模态条件均值都至少+0.3pp，对原锚点均不低于−0.1，单条件最差tile相对C0不低于−0.2；fixed8000两方向增量同号。若只有一侧成立，只记录单向线索，不宣布双向能力或自动续训。
- F：F1对F0旧S至少+0.2pp且满足A同样clean/逐tile/双方保留底线；再看F1与F2/F3的预设方向性干预，不因某一最高值重写候选。若频率收益仅体现在几何族/边界但整体未过，保留局部描述，不直接升级贡献。
