**保护有方向性效果，但没有解决信息取舍。** P综合+0.041182pp、fixed8000 +0.066432pp，四族selected都微升；QD中RGB锚点正确被融合伤害的比例从1.340385%降为1.206921%（相对约9.96%）。主条件仅RGB正确集合保留率95.8809%→96.2828%，仅DSM正确集合38.0316%→35.6581%。它更保守地保住RGB，同时丢掉一些DSM独有价值。0.04pp不能声称显著或稳定实际优势，也未达到预设综合+0.2pp门槛。

**原恢复配方的负面效果在四质量族与固定训练末尾都存在。** R综合−2.013409pp，fixed8000 −2.053585pp；clean、QR、QD、QJ均下降。仅DSM正确保留38.0316%→59.9342%，但仅RGB正确保留95.8809%→90.9747%，QD伤害率1.340385%→2.828777%。该配方确实改变了取舍，未同时保留双方信息；不同正确集合的分母不同，不能把保留百分点相减当作净像素收益。

**面积缩放明显缓解损失，但“恢复到基线附近”不等于方法增量。** PR_area对原S1综合+1.730941pp，比PR_pixel的+0.503985pp更大；PR_area仍比S0低0.064718pp、比仅保护P低0.105900pp，四族均低于S0。PR_pixel仍比S0低1.291674pp。结果支持恢复项的有效作用强度/归一化方式值得解释；尚不能认定区域占比是唯一根因，也不能确定PR_area只是近似关闭恢复项——这要看实测恢复区域比例、加权loss、梯度范数和保留率。

**不是负交互导致失败。** 2×2原四格S0/P/R/S1的综合交互S1−P−R＋S0为+0.176568pp，fixed8000 +0.162126pp；保护在恢复存在时仍提高约0.217750pp。正交互只部分抵消恢复配方损失，无法将S1推到S0以上。不能据此证明梯度方向没有冲突；指标交互和梯度余弦是不同证据。

## 已验证与仍未决

阶段实验已验证（用户终端运行证据）：四项新训练及两项重放完成，四continue均False；原静态恢复监督产生明显保留取舍，面积缩放缓解pooled下降但没有取得预设增量。这是单seed、两开发tile、当前架构/退化/权重下的结论。

代码已实现：两类归一化、同mask对照、梯度范数/余弦诊断、固定checkpoint路由重放、原始int64计数保存。实现不代表这些诊断结果已经分析。

尚未决：
1. PR_area/PR_pixel的selected保留率、QD伤害、fixed8000、最差tile/condition、逐类变化，尤其建筑/树木/车辆，不能由综合分推断。
2. 原权重G0/G1在uniform及单专家强制权重下是否改善。重放保留各专家残差、可用性回退，只改变混合权重；专家模式还包含共享/基线结构，不能误读成重新运行RGB/DSM单模态模型。没有screen中的interventions结果不能判断路由本身失败还是专家本身欠佳。
3. 恢复区面积、类别组成、有效加权恢复梯度与CE/保护梯度的比值/余弦如何变化。少量负余弦不足以认定唯一梯度冲突因果。
4. 完整原矩阵、预测/checkpoint/source SHA的离线重算与绑定验收。像素数很大不等于独立样本很多；此轮没有多tile/跨域确认依据。
