## D27根因、修正与下一步

D27最后观测2026-10-03T04:12:45.117489+08:00 COMPLETE_WITH_TECHNICAL_FAILURES，十组同KeyError，screen为INCOMPLETE_NO_SCIENTIFIC_GATE。接力本身成功：首G0/G1于04:05启动，D2604:04完成；失败后controller继续领取剩余组直到04:12。

根因在run_rebuild_v1_d27.py：只把torch tensor字段转到GPU，丢掉字符串列表treatment，再把这个过滤后的字典交给需要treatment的objective。数据集本来正确提供字段，不能误改退化生成或损失取消专家辅助监督。旧CPU检查直接构造完整batch调用objective，没有经过真实worker传递环节，漏检该接口。

修复加入d27_data.training_batch，保留合法的逐样本treatment列表，tensor正常转device，检查长度与physical batch一致；worker统一调用。新增模型回归覆盖转移→objective→backward。已本地执行实际torch CPU转移、strata匹配、长度错误拒绝、worker调用及Python3.10语法检查；完整模型新回归尚未在本轮运行，不称CUDA已验证。
