# B2/B3 结果与论文结论边界（2026-09-21）

## 1. 证据范围

本记录对应 Potsdam Train16 -> Val2、seed42、`3_11` 与 `5_10` 两个验证 tile，主指标为 `mIoU_fg5(noboundary)`。B2 的五条对照臂和 B3 的配对局部退化诊断均已由服务器输出完成；本仓库保存的是用户终端输出的精简转录，服务器原始 CSV、日志、混淆矩阵与 checkpoint 仍是最终核验来源。本轮未访问 Test6。

## 2. 这条路线验证什么

这条路线不是在证明“缺失 DSM 已被完全解决”，而是在拆分以下三个问题：

1. **继续训练收益**：C 是相同 R05 初始化和 4k 预算下的 CE continuation，用于排除单纯继续训练带来的提升。
2. **普通蒸馏收益**：R05_KD 只使用双模态 R05 教师，用于判断普通 teacher-student 压缩本身是否有效。
3. **可靠性教师收益**：KD 使用 SafeMaxConfidence 教师目标；在已知合成缺失区强制采用真实 Optical-only R01，其余位置在 R01 与 R05 之间按置信度选择。它检验的是“避免把不可靠 DSM 教师预测传给学生”是否优于普通 R05 教师。

SAFE 在 KD 之外加入显式 Optical fallback 约束，用于检验额外约束是否必要；AVG_KD 是平均教师对照，用于排除简单融合即可解释结果的可能性。学生推理时仍是 RGB+DSM 双输入，不接收缺失掩膜，也不存在结构化 Optical-only 分支，因此不能称为已经学习出完整的缺模态回退机制。

## 3. 全局退化结果

| 方法 | clean | DSM down8 | DSM zero |
|---|---:|---:|---:|
| C | 86.9976 | 85.6900 | 83.0949 |
| KD | 87.2223 | 86.2175 | 83.7867 |
| SAFE | 87.2998 | 86.3802 | 83.6187 |
| R05_KD | 87.4440 | 85.9955 | 83.6299 |
| AVG_KD | 87.2595 | 86.0029 | 83.5725 |

数值单位均为百分点。相对 C，KD 在 clean、DSM down8 和 DSM zero 上分别提高 0.2247、0.5275 和 0.6918 个百分点。SAFE 相对 KD 在 clean 与 down8 上分别增加 0.0775 和 0.1627 个百分点，但在 zero 上下降 0.1679 个百分点，尚不能证明显式 fallback 约束具有一致收益。

R05_KD 相对 KD 在 clean 上高 0.2217 个百分点，但在 down8 和 zero 上分别低 0.2220 和 0.1568 个百分点。这说明单纯采用高精度双模态教师更偏向 clean 性能，而可靠性教师在 DSM 退化条件下具有更稳定的方向性。

## 4. 配对局部退化结果

B3 对相同像素区域比较 clean 与 corrupt 预测，从而减少“该区域本来就难”对结论的混淆。配对结果表明，局部 DSM 缺失与局部 DSM 降采样是不同难度的问题：所有方法在局部缺失区的下降均明显大于局部 down8。

与 R05_KD 相比，KD 在 2 个 tile、2 类退化、2 类区域（damaged 与 boundary）构成的 8 个比较中均具有更小的指标下降。按 tile 计算，KD 相对 R05_KD 的下降改善范围为 0.0192–3.2908 个百分点。该结果支持“可靠性教师目标能减少不可靠模态知识迁移”的解释。

但 KD 相对 C 的优势并不普遍：汇总后，KD 在局部缺失 damaged 区仅少下降 0.0551 个百分点，而 boundary 区反而多下降 2.6510 个百分点；在局部 down8 上，KD 的 damaged 与 boundary 下降分别改善 0.3326 和 1.8050 个百分点。因而当前证据支持可靠性教师优于普通双模态教师，但不足以声称其在所有局部故障区域均优于 CE 基线。

boundary 指标在不同象限出现较大正负波动，反映其区域较薄且类别支持量有限。论文中应把 boundary 作为机制诊断，主结论仍以全局指标与 damaged 区配对变化为准。

## 5. 当前结论分级

- **代码已实现**：普通 R05 教师、SafeMaxConfidence 可靠性教师、平均教师和 fallback 约束对照均已具备独立训练/评估入口。
- **实验已验证（seed42 阶段证据）**：KD 相对 C 在三种全局条件均为正；KD 相对 R05_KD 在全局 DSM 退化和全部八项局部配对比较中方向更优。
- **尚未确认**：可靠性教师的增益能否跨随机种子复现；是否优于 CE 的局部缺失 boundary；是否能推广到其他数据集或真实传感器故障。
- **不得表述**：不得写成已解决任意 DSM 缺失、已学习缺失检测器、推理时具备真实 Optical-only fallback，或已获得跨数据集普适性。

## 6. 可用于论文的克制表述

### 方法定位

为降低辅助高程模态退化时错误教师知识的迁移，本研究构建了可靠性感知的双教师蒸馏策略。该策略在已知合成缺失区域采用光学单模态教师提供软目标，在其余区域依据预测置信度从光学教师与 RGB–DSM 教师中选择监督信号，并将所选概率分布蒸馏至单个双模态学生网络。该设计的目的不是在推理阶段显式切换网络分支，而是在训练阶段约束学生减少对不可靠 DSM 预测的继承。

### 结果表述

在 Potsdam Val2 的 seed42 实验中，可靠性教师蒸馏相对匹配的 CE continuation，在 clean、DSM down8 和 DSM zero 条件下分别提高 0.2247、0.5275 和 0.6918 个百分点。相较仅使用双模态 R05 教师的普通蒸馏，可靠性教师在两种全局 DSM 退化条件下分别提高 0.2220 和 0.1568 个百分点，并在局部退化的八项 tile–区域配对比较中均表现出更小的性能下降。上述结果说明，训练阶段的教师目标筛选能够在本次验证设置下减少不可靠 DSM 知识的传递。

### 局限性表述

该收益目前仍属于单随机种子的阶段性证据，且在局部完全缺失的交界区域未稳定优于 CE 基线。由于学生网络仍保留 RGB–DSM 双输入结构，当前方法不能等同于具备显式光学回退分支的缺模态系统。后续需通过 seed17 的匹配复验确定方向是否稳定，再决定是否将其提升为论文主方法结论。
