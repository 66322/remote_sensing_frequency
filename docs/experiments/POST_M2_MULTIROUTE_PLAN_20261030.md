## 4. 六条研究路线与最小可解释实验

### A：表示能力与读出瓶颈（保留并拓宽原A0）

问题：没有收益是表示本身缺信息，还是1×1低分辨率读出用不出信息？原A0两模型×2k照原合同接续。新增同容量轻量空间读出各2k，构成DINOv2/3×线性/空间读出2×2。新读出仍匹配A0输入、NB/128监督及训练样本流；不把改变监督分辨率混成教师效应。

观察骨干主效应、读出主效应及交互，另在训练内分层看小车、边界、建筑/树木混淆。A0阴性只限制该浅头，不能否定S结构路线。若只有读出有效，优先S；若DINOv3跨读出均有增量，再进入原A1四臂。A2普通教师/对应破坏仍保留。MM-DINO已直接进行DINOv3多模态遥感分割，换DINOv3或LoRA本身不算新贡献。

首次四探针合计8k，其中原A0 4k、新增4k；DINOv3不可用时A分支等待来源/加载，G/Q/S继续。扩大真实物理视野、打乱周边、关系探针另立A-context诊断：中心GSD固定，禁止缩放整图冒充扩大上下文；成本独立登记，不藏在8k里。

### G：DSM的几何作用与配准容忍

问题：局部高差何时能排除RGB错误连接，何时由于错配/表面噪声应弱化？从关系图/空间注意力入手，而不是重复DSM类别概率投票和旧3×3传播。

四臂：B1普通融合；G1普通可学习空间亲和度加固定相对高差先验（DFormerv2式适配）；G2局部结构/对应可靠性约束的几何关系；G3与G2同容量但训练/推理使用固定空间对应破坏。G1/G2匹配实际可训练容量与支持范围，避免将可靠性分支多出的参数记为几何机制。先用输入局部统计定义可观测性；未知质量不读取真值错误掩码。相对高差在加常数高度偏置时应基本不变，平移DSM则应改变对应；这两种干预的预期不可混淆。

主指标建议：预定DSM平移压力下full fg5相对G1至少+0.5pp；clean下降不超过0.2pp、最差tile不低于−0.5pp。正确对应应优于匹配破坏，普通边缘/高度距离解释全部收益则收回新关系机制。验证鲁棒性与正确几何收益须同时报告。AMMNet、DFormerv2、BATFNet和DLGCNet属于近邻；G1只算机制控制，投稿阶段须补直接近邻统一协议复现，不能把简化适配冒称原方法完整复现。

新增3×8k=24k；不等待A0。主干、头和监督沿B1，失效仅关闭本实现。

### Q：局部质量变化与训练暴露分配

问题：局部未知退化时，能否通过训练分布设计学会利用另一模态，而非靠人工zero标记或GT故障路由？MIAM和SGMA提供失衡训练启发，但不能直接继承其任务收益。

四臂：B1普通增强；Q1固定、均衡的RGB/DSM局部损伤训练；Q2根据训练内能力/收敛状态调整损伤分配；Q3冻结Q2生成的掩码面积、频率、严重度和模态比例总暴露分布，预先打乱时间顺序后重放，取消与当前状态的对应。Q2/Q3依赖按顺序执行；完全同序重放可能复现同一轨迹，不能作为反馈因果控制。Q3检验时序/状态对应是否超出总暴露分布，不单独证明闭环反馈因果性。不把掩码总预算不相等的比较归因为“动态”机制。保持总样本和更新预算，信号只来自训练/内校准；频域掩码如追加，另与同面积/能量的空间退化对照。

主指标建议：预先登记、未参加该组增强的RGB模糊和DSM平移两条件full fg5均值相对Q1至少+0.5pp，并保护clean/健康区≥−0.2pp、最差tile≥−0.5pp。down4作为已见条件诊断，不用已见增强成绩宣称自然故障泛化。动态不胜固定/重放，关闭闭环创新，保留实用增强结果。缺失模态另用已知缺失与未知损伤两个面板，已知mask只给双方相同的合法输入。

新增3×8k=24k；不等待A0，也不把EDL作为前置。

### S：高分辨率读出、边界/小目标与频率的独立价值

问题：冻结表征的粗网格、上采样和监督是否比融合策略更限制分割？迁移LiDeRe/AnyUp的读出/特征上采样思路，再检验DSM结构有无额外价值。

首组四臂：B1普通解码；S1 RGB引导的高分辨率空间细化；S2同结构和容量改用RGB＋DSM相对结构引导；S3对应破坏的S2。S1/S2保持相同输出尺度、训练Full监督和像素损失归一化，不能把更多标注像素或更大解码器误记为DSM收益。AnyUp公共预训练权重与LiDeRe官方实现可作为强读出对照：先核版本/输入/成本；实现灵感版必须写“适配”，不冒充完整复现。

主指标建议：Full标签边界F1相对S1至少+0.5pp，full fg5和非边界区域下降不超过0.2pp；边界容差用GSD固定物理距离，报告原像素口径；Car IoU/召回和类别分区同时报告。小语义连通域只能叫小区域，不假装有实例标注。边界改善但整体损伤过大不通过。

新增3×8k=24k；不等待A0。之后独立S-frequency三臂：普通空间高通/边缘残差、频率残差、保留频带能量的空间对应破坏；同带宽/参数/监督/预算。建议额外3×8k=24k，仅当S首组显示结构瓶颈时进入；不把原D26换窗口算新问题。

### C：特权信息与恢复/蒸馏

首组4×8k：受限输入普通增强；普通logit KD；匹配feature/relation KD或分阶段GKD控制；候选几何约束的关系/特征恢复。所有学生相同、教师相同、监督样本相同；GKD若增加预蒸馏阶段，其更新、数据和算力额外单列，并给候选同样预算，不可与单阶段8k直接归因。教师拟合/复验成本另列；教师若复用B1，必须是同训练区且真实存在的合法端点。教师在训练内校准上无优势则暂缓该特权源，不停止其他路线。

主指标建议：未见RGB退化下受影响区域full fg5比最强普通KD至少+0.5pp，clean/健康区≥−0.2pp；仅PSNR、特征距离、教师准确率改善不通过。D15的2–3pp是融合对RGB的差，不是本路线预计新增收益。恢复监督不能从DSM唯一还原不可识别纹理；以分割任务信息和净纠错评估。
