## 2. 本版实施选择

- 数据：Potsdam Fit12/F0沿服务器旧M2 folds.json的确切6拟合/2内校准/4外层开发列表，排除512像素边带；不按计数重建列表，不开Val2/Test6/held4/final。
- RGB/DSM：原RGB与float32原始DSM，5cm GSD。使用有效DSM中位数逐tile中心化，除以六个拟合tile抽样得到的固定q95−q05；不称nDSM。NoData填中位数并携带可观测有效值，DSM平移时有效值一起移位。
- 骨干：已验收DINOv2-S本地源码/公共权重，冻结；DINOv2补至518、37×37特征，固定bfloat16前向。新头float32参数、bfloat16 autocast，Full 512×512全像素监督。
- 普通头：96通道DINO投影+RGB浅层1/4分辨率支路+辅助槽，两层空间融合。B0辅助槽来自RGB灰度和局部残差；B1来自DSM+有效值，所有参数参与前向反传。
- G：64×64网格、5×5支持，先学习普通空间亲和度，再加入相对高差；G2可靠性仅由RGB局部差与高差的可观测一致性得到，无GT错误mask。G3只破坏几何引导的对应，不替换底层普通DSM分支。
- S：同结构同容量引导细化；S1使用两种RGB局部残差，S2第二槽改为DSM局部相对结构；S3固定错配该结构。属于本任务适配，未冒称LiDeRe/AnyUp官方完整复现，入围后仍需最近强方法统一协议。
- 训练：有效batch16，AdamW lr3e−4、wd0.01、betas0.9/0.999，梯度范数clip5，六类无类别加权CE，按全batch有效像素总量归一化；microbatch累积不各自重新平均。固定8k，无自动延长或第三seed。
- 可训练参数：B0/B1/Q1/Q2/Q3各316,166；G1/G2/G3各328,582；S1/S2/S3各486,246。匹配在各机制组内；不将S相对B1的额外容量直接当DSM贡献。A空间头两骨干各19,254参数，原线性头为2,310；2×2解释是读出配置变化，不冒称线性与空间头同容量。
- Q：每样本清晰概率0.5，其余在RGB或DSM施加局部down4。Q1损伤模态均衡；Q2每100步从训练损失更新损伤模态概率，限定0.25–0.75；不追加教师/反事实前向。Q3按固定seed打乱Q2完整批次暴露记录，严格保留面积、位置、严重度、模态总分布。该控制不能单独证明闭环因果性。

## 3. 评价与选择冻结

五条件：clean、局部RGB down4、RGB局部高斯模糊σ2px、局部DSM down4、DSM局部平移16px（0.8m，向下，边缘复制）。局部区域为tile边长一半的正方形，位置由tile+seed42确定，所有作业共用。模糊与平移不参加Q组训练增强。G还需后续高度偏置与配准机制确认，未藏入首批预算。

Full边界F1：前五类逐类边界、欧氏4px/0.20m匹配，保存双向匹配数与各边界总数；忽略区域邻近边界排除。另存Full/NB、ROI/健康区、边界带/非边界6×6 int64矩阵、逐tile与Car IoU/召回。

4k/8k两个内校准点各2tile×5条件。端点选择只用预定指标：B0/B1 clean Full fg5；G DSM shift Full fg5；Q unseen blur/shift平均；S clean边界F1；平局取较早端点。外层开发不能选端点。主判据+0.5pp、clean≥−0.2pp、最差tile≥−0.5pp，Q保护健康区、S保护非边界；对应/时序控制须有正差距。阈值是开发筛查，不是显著性。

强基线资格：末三段平均loss低于前三段且内校准clean Full fg5≥50%，否则INVALID，停止依赖派发。其他未学会只阻断本路线后继，不能作科学阴性。普通控制学会且候选未胜，完成必要对照后按路线复盘，不调参加种子。
