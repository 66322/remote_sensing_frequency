## 1. 建议结论与角色

2026-10-22用户补充：研究问题有重复很正常；可以更好解决已有问题，或移植其他领域方法，应多视角考虑。本草案据此将“问题是否空白”与“解法是否有实质贡献”分开。新增第11节列出方法层面的可验证候选。研究问题成熟不构成否决；仅仅替换算子而缺少机制与公平收益证据，才不足以支撑当前贡献目标。

建议继续利用遥感影像与几何的积累，但停止把“再加一个融合模块”当成默认研究问题。近期先检验RGB条件下的几何证据能否被更好利用；深入方法优先考虑测量一致性或对应不确定性；若换任务，再按实际失败模式选择高度变化或对象结构。换一个骨干或损失本身通常不能解决当前贡献不清晰的问题。

## 2. 目前证据究竟否定了什么

- **实验已验证，开发证据：** M1的幅度配方未通过原门禁。M21相对M11的DSM standalone增益在两seed为+1.161、+0.303pp，但down4补救差为+0.530、−0.906pp，指定融合比较也未稳定兑现。不能继续用单模态涨分替代互补价值。来源：[M1验收与路线复核](PHASE3_M1_ACCEPTANCE_AND_ROUTE_REVIEW_20261015.md)。
- **代码已实现：** 近期Phase2与Phase2.4主要对独立专家输出做权重/残差调节；可用信息和输出动作受具体结构限制。这不能直接外推到全部联合表征。
- **历史探索证据：** D18、D25已出现普通融合收益；D26、D27也做过跨模态交互/残差专家。因此不能说此前从未研究特征融合，也不能将其阴性结果统一称为“配准失败”。来源：[D25](D25_MISSINGNESS_RESULTS_20261002.md)、[D27](D27_FINAL_REVIEW_20261003.md)。
- **证据不足：** 目前没有证明主要误差来自真实空间错位、标签错误或建筑拓扑。Phase1.5 ECI约1.02不支持直接假定边界是唯一主瓶颈。
- **尚无结果：** M2仍未运行。108个训练是对一个假设的系统检验，作业数量本身不证明假设成立或论文创新。279只是条件上限，不是应当全部跑完的目标。

结论：若M2失败，首先关闭相应的误差加权假设；不自动否定RGB–DSM研究问题，也不自动增加种子、延长训练或换骨干救场。

## 3. M2结果如何影响后续，而不是重新挑最好数字

以[2026-10-16执行补充](../protocols/PHASE3_M2_EXECUTION_20261016.md)的H1/G1、H2、G2–G4实际作用域为准，不能混用旧M1保护规则。

| 结果组合 | 能支持的解释 | 后续用途 |
|---|---|---|
| H1不成立 | 对应性监督未稳定创造额外DSM补救 | 停止同类加权扩展；J只诊断表示/动作限制，或转S/T的真实观测问题 |
| H1成立、H2不成立 | 一般困难位置有效，尚无退化特异性 | 保留一般结论，停止退化特异扩展 |
| 补救增加、G2不成立 | 单专家补救没有兑现成当前融合收益 | 比较不受限logit头和特征交互；检查概率幅度与正确类别间隔 |
| G2成立、G3不成立 | 收益与正常区域/其他故障损伤存在权衡 | 报告权衡；有实际应用需求才另立选择性预测，不能事后改保护门槛 |
| G4不成立 | 对RGB实例或未见退化的依赖仍大 | 查机制与场景迁移；不靠增加旧种子代替新地理场景 |
| 全部成立 | 当前开发协议支持推进 | 按原门禁决定B；仍须最近工作对照、独立地区与完整论文证据 |

已有预测/充分计数可用于原因分析，但“两个专家都错、联合预测正确”不等于测得信息论协同量。专家top-1的选择oracle也不是任意联合分类器的理论上界。

## 4. J：把“信息不足”和“利用方式不足”分开

问题：DSM是否必须先独立完成类别预测，才能帮助RGB？高度结构可能对RGB条件下的类别判别有用，却不适合独立分类。这是待检验解释。

先用M2未来产生的合法外层RGB参考和D0专家；目前尚不存在这些新fold权重。旧全Fit12微调专家不能用于新外层holdout。M2若不执行，须另建合法训练，不能假装零成本复用。

固定专家、训练数据、空间感受野和评价流程，比较：

| 臂 | 作用 |
|---|---|
| 已冻结概率混合 | 零新增训练的参照 |
| J1 不受限logit MLP | 检验输出动作限制，允许产生不同于两专家top-1的类别 |
| J2 RGB+DSM特征联合头 | 检验输出压缩前是否还有可用条件信息 |
| J3 参数/感受野尽量匹配的RGB单模态头 | 排除仅增加容量和上下文 |
| J4 RGB/RGB双模型特征头 | 排除普通集成多样性；同fold、相同单模型训练预算 |
| J5 对应关系打乱的DSM特征头 | 与待检验条件头同结构，检验对应关系必要性，配对规则预先固定 |
| J6 RGB条件的几何证据头 | 检验条件交互能否更好利用已有表示，对应11.1 |
| J7 移除RGB条件的几何证据头 | 保留RGB基础输出，匹配条件头容量，检验条件项本身 |

J4可以使用M2同fold另一个RGB seed，必须提前固定轮换，不按分数选择。报告每臂可训练参数、FLOPs和输入维度；无法完全匹配的部分明确列出。

建议可行性预算：7个新头×3fold×2个预先固定seed×8k更新＝42作业、336k头部更新；这是规划估算，尚未登记。2seed用于筛选，不能写成确认性结论。模型输出无实质学习、数值错误或未达到可比较收敛时只能判为无效/不充分，不能判科学阴性。

解释顺序：J2只胜旧混合而不胜J1，优先解释为动作限制；胜J1却不胜J3/J4，不能排除容量/集成；同时胜这些对照且J5失去收益，才追查具体条件几何。J5失效仅说明对应关系重要。

冻结专家、仅训练新头的阴性结论只覆盖当前表示与训练预算，不能否定端到端联合学习。确有表示丢失证据时，另立一次容量与预算匹配的联合训练对照；不无限扩头、改loss。

新颖性边界：[CMX](https://arxiv.org/abs/2203.04838)已有RGB-X特征交互；[DMIL，CVPR 2026](https://arxiv.org/abs/2606.11614)已研究独立集成/联合学习利用不同信息成分的问题。因此J是路线选择工具，“改成特征融合”不是足够的新贡献。

## 5. S：从可靠性标量转向不确定/不存在的空间对应

候选问题：同一个地理对象在RGB与DSM中未必逐像素对应；强制选一个匹配位置可能注入错误几何。能否在可匹配时使用几何，在多解或无对应时保留不确定性？

可借用机器人视觉的局部匹配、部分匹配/无匹配机制，以及医学配准的概率位移估计。借的是“对应分布及无对应状态”，不机械套用医学图像强度相似性或可逆形变假设。[SuperGlue](https://openaccess.thecvf.com/content_CVPR_2020/html/Sarlin_SuperGlue_Learning_Feature_Matching_With_Graph_Neural_Networks_CVPR_2020_paper.html)、[概率配准](https://arxiv.org/abs/1903.03545)。

**先做不训练的鉴别：** 固定RGB和标签坐标，对DSM分别施加已知平移、局部位移、局部无对应/缺测；保持相同有效评价支持，显式标记插值及边缘区域。已知逆变换只作为合成条件oracle。观察正确恢复对应能否明显恢复任务表现，检查现实数据是否存在同类偏差。跨时相新建物体导致的无对应不能由平滑位移“修复”。

五个核心训练臂：普通逐位置融合；仅错位增强；确定性硬配准后融合；软对应但强制匹配；软对应加无匹配状态。容量、感受野、训练增强和优化预算尽量匹配。与普通特征交互相比的增量应当来自明确的对应处理。

主评价同时覆盖正常场景、真实错位场景、未见位移类型、无对应区域。除分割主指标，报告可匹配区的匹配误差、无对应识别、使用DSM的区域比例、每类和每场景损伤。对比同等DSM使用比例，防止靠全部回退RGB得到表面安全。无独立配准真值时只称任务表现及合成标定，不声称真实位移准确。

**停止条件：** 错位增强或现成配准已经解释全部收益；无匹配状态不能优于同等覆盖率的简单拒绝；正常场景损伤超过预登记容忍；真实场景没有该问题或只有人工平移有效。遇到这些结果关闭此候选，不添加更大的对齐网络。

如果数据同时存在标签粗化，先做“传感器错位×标签粗化”的2×2正交干预，统一用原精标评价，比较硬标签、边界忽略、标签松弛、区域聚合监督，分清观测问题与监督问题。不能通过删边界或修改评价真值制造收益。[WACV 2023标签分辨率工作](https://openaccess.thecvf.com/content/WACV2023/papers/Workman_Handling_Image_and_Label_Resolution_Mismatch_in_Remote_Sensing_WACV_2023_paper.pdf)已经覆盖普通分辨率不匹配，故新主张必须更窄。

## 6. T：转向“真实高度变化还是观测误差”

候选问题：旧DSM与新影像之间的差异可能来自建设/拆除，也可能来自横向配准、垂直基准、季节外观或观测遮挡。能否避免把这些混淆为真实变化，并正确估计变化的位置、方向与高度？

这是换任务，须单独定义输入合同。两时相RGB、两时相DSM、旧DSM+新RGB三种设置不能放在一个表里假装输入公平。优先评估“旧DSM+新RGB”的资源受限设置；新DSM只作预先声明的训练监督/评价真值，不作推理输入。双DSM传统差分是额外信息参考，不能当相同输入预算的竞争方法。

可迁移的概念是测量误差建模、鲁棒估计和变化检测中的干扰因素分离。候选模型把全局/缓慢变化的位置与垂直偏差和局部真实变化区分开；但不能将真实变化全部吸收到配准场里。只有旧DSM+新RGB时可能存在不可辨识区域，应允许不确定性，并明确需要哪些训练监督和假设。

建议五臂：同输入简单跨模态变化基线；成熟同输入方法；显式配准/基准校正的简单两阶段方案；只做干扰增强；候选的干扰—变化分离模型。双DSM差分及已知逆变换仅作注明额外信息的诊断。不得用评价集真实不变区或变化标签来估计推理时的偏差。若先用双时相完整DSM辨识偏置机制，须单列为机制实验，再检验旧DSM+新RGB是否仍有足够可辨识信息；不能跨输入合同继承结论。

设计真实无变化、真实变化、合成仅干扰、真实变化叠加干扰四类面板，锁定空间支持和标签坐标。至少分别记录变化F1/IoU、变化区域高度误差及正负方向、无变化区假警、每城市结果。核查高度变化真值是否由DSM差分生成及如何清理，避免用同一有偏差差分同时充当输入和验证真值。只提高全图RMSE可能来自大量不变像素，不能独立证明变化估计改善。

**停止条件：** 普通配准/鲁棒偏差校正等效；方法通过抹除真实变化减少假警；优势只来自额外新DSM输入；真实数据没有可辨别的干扰；跨城市或自然观测误差中失效。

公开入口已核实，但未下载验包：
- [3DCD官方代码](https://github.com/VMarsocci/3DCD)及[新版数据入口](https://sites.google.com/uniroma1.it/3dchangedetection/download)：官方新版明确含地理参考影像与原始DSM。原任务从双时相光学影像预测2D/3D变化，改作其他输入须另立协议。代码注明研究/非商业用途，数据条款还须随下载核对。
- [Hi-BCD官方MMCD](https://github.com/HATFormer/MMCD)提供三城市跨模态建筑变化数据入口，精确输入、标签生成与许可须验包；不能把patch数当独立城市数量。
- [DPG-CD，2026预印本](https://arxiv.org/abs/2605.07151)已直接研究旧DSM+新影像、深度先验和联合2D/3D变化。输入组合和增加高度辅助任务本身均不是新意；还须细读其干扰处理及同类注册/变化联合方法。其NYC-MMCD不能按论文提及就视作已可下载。

## 7. V：从像素分类转向可用的建筑对象

候选问题：在遮挡、几何缺测或错位下，建筑是否被粘连、切碎，孔洞和轮廓是否合法？几何是否对这些对象级错误有超出普通像素正则的帮助？

可借用计算几何、图结构或拓扑约束，但先明确目标是屋顶、建筑基底还是语义建筑区域。现有语义building标签不自动等于实例或矢量真值；impervious surface也不等于道路网络。

先固定RGB、几何和普通融合三个基线，确定实例合并/分裂、轮廓和孔洞误差是否实际存在，再比较普通分割后矢量化、固定几何后处理、成熟矢量预测方法及候选结构学习。加入等预算RGB正则、打乱几何对应对照。报告对象召回、合并/分裂、轮廓误差、几何有效率与像素IoU，防止用漏检复杂建筑换取“有效多边形”。

[P³官方项目](https://github.com/raphaelsulzer/PixelsPointsPolygons)和[数据卡](https://huggingface.co/datasets/rsi/PixelsPointsPolygons)提供RGB、航空LiDAR与建筑多边形，跨三洲，数据卡标注CC-BY-4.0、全量约163GB。已有影像/几何/融合和成熟矢量基线，故“换P³做融合”不是新意。若为本篇使用派生DSM，需固定栅格化、有效点数和空洞标记；航空LiDAR派生栅格不等同于现有摄影测量DSM。另建数据和运行索引，不合并另一篇点云论文。

**停止条件：** 成熟后处理已解决主要结构错误；像素漏检解释全部结构变化；候选只靠增加参数或普通边界正则获益；跨地区无收益。若成立，论文主指标和问题应正式转为对象几何，不能仅加结构损失后仍只报告mIoU。

## 8. 哪些交叉方向暂不值得排长队

- 普通DSM特权监督/蒸馏已有直接先例：[Geometry-Aware Segmentation via Implicit Height Estimation](https://arxiv.org/abs/2006.05848)。只有“部署拿不到DSM”的真实约束及新机制才值得单独立题。
- 选择性预测只有存在拒绝/人工复核流程时才换了决策问题。比较同覆盖率的RGB熵、模态分歧、随机及学习分数，报告类别覆盖率和处理成本。[SelectiveNet](https://proceedings.mlr.press/v97/geifman19a.html)已有成熟框架。两个tile的相关像素不能支撑跨城市风险保证。
- 信息获取要有真实成本；先读取DSM再决定是否“获取DSM”不成立。
- 换Mamba、扩散、SAM、频域模块、PID损失或更大骨干暂不单列路线。仅当明确失败模式要求这些工具、且简单对照不能解决时再使用。
- 旧幅度配方、旧门控失败配方不自动复活；新条件不应被用来事后寻找有利结果。

## 9. 如何安排足够深入的实验，而不是单纯延长运行

| 阶段 | 解决的疑问 | 建议规模与出口 |
|---|---|---|
| 0 数据与问题鉴别 | 真实失败模式是否存在，标签/输入是否支持该问题 | 元数据与训练开发样本审查；零新增训练的干预分析；不读封存test |
| 1 J或新任务强基线 | 利用方式受限还是简单方法已足够 | J约42个小头作业；新任务先复现同输入基线，不同时铺开S/T/V |
| 2 一个候选机制 | 候选是否胜过最强简单解释 | 约5臂×3地理开发划分×2固定seed＝30作业；监督预算按任务另冻结 |

| 4 论文确认 | 完整对照、独立泛化、成本和失效边界 | 冻结协议与最终模型后才另行开放相应test，保存所有负结果 |

阶段2的三划分必须有真实地理意义且数据支持；城市不足则如实降低推断范围，不能凑三个随机patch划分冒充三城市。阶段2/3不把故障种类、mask或像素当独立样本。报逐地区差值、预定seed重复性与按地区组织的区间；独立地区太少时不宣称显著泛化。

进入长程训练之前，须为选中的任务冻结：主比较、最小有用收益、正常条件容忍、评价支持、异常终止条件及计算预算。阈值根据任务意义、标注分辨率和基线误差制定，在看候选结果前锁定；本草案不把旧M1/M2阈值直接移植到新任务。

资源以更新数、训练样本数和实测秒/步记账。两GPU独立作业并行；CPU有界统计，RAM消费后回收，必要端点与轻量原件落盘。不同网络/数据的336k与3.456M更新不能直接换算相同耗时。首次正式运行记录稳定吞吐，再估训练、评价和上传各项时间，不承诺“一天/数天”。

长实验的价值来自明确反事实、强对照、真实条件和独立地理验证。一个核心机制加这些证据可以形成持续的研究；把四个方向全部排满两卡只会增加难以解释的结果。

## 11. 方法迁移：成熟问题也可以做出更好的解法

这里不要求原问题无人研究。可接受的贡献包括：在相同输入与计算条件下改善已有任务；用新的可检验机制处理现有方法的特定失效；或把另一领域的方法改造为适合遥感观测与评价的解法。直接移植先作为基线，改进部分由消融与跨条件效果建立。以下均未实现、未验证。

### 11.1 条件几何证据：借鉴视觉问答的条件调制

改变DSM的职责：RGB提供“当前有哪些语义解释”，DSM提供支持或反驳这些解释的局部几何。一个最小实现为：

`z_c = z_RGB,c + <U_c f_RGB, V g_DSM>`

它是按类别输出的低秩双线性修正，或用FiLM调制几何特征；不限制为两个语义logit向量之间的一个标量插值。主监督为联合分割，第一版不强制几何分支独立预测所有语义类。缺失状态须显式输入；完全缺失时修正精确为零。局部缺测周围仍需评价传播范围。

[FiLM](https://arxiv.org/abs/1709.07871)提供条件调制范式；这里可研究的适配是语义条件下哪些高度差、局部结构和有效观测有用。高度差不等于地面归一化高度，“高”不直接等于建筑，不能把这类经验规则当真值。

先分开两个问题。J阶段冻结已有专家，只比较条件头、无条件头、普通拼接、logit MLP、RGB容量/集成和打乱对应对照，检验已有表示的利用方式。它不能检验过去的DSM独立CE是否损伤了表示。

只有进入后续表示学习实验，才用相同公共初始化与训练范围，比较普通联合拼接、条件几何（无独立DSM CE）、条件几何（有独立DSM CE）。几何编码器或适配器实际可训练；普通拼接也采用相同可训练范围和预算。预留3臂×3fold×2固定seed＝18作业，步数另冻结，这不是自动新增队列。普通拼接若同样有效，接受更简单方案，不把双线性运算本身包装为贡献。

可检验预测：几何可用的混淆类别上，条件版本比无条件版本更少误改；关于独立DSM语义目标是否限制条件表示，只能由上述可训练表示实验中有/无该目标的比较支持。但若普通拼接、RGB扩容或集成解释全部收益，就关闭该机制解释。此路线是J诊断的一个具体实现选择，并不声称历史上从未有条件交互。

### 11.2 测量一致性：借鉴医学成像与逆问题

将DSM当成经采样、平滑、错位和缺测得到的观测，而非另一个RGB式分类输入。可检验近似为：

`D = M [S_s K_sigma W_delta h + b] + epsilon`

h是潜在几何状态，M是有效观测，S/K/W分别为采样、有效平滑及空间变换。采用少量“观测残差更新＋RGB条件更新”，最后从RGB和几何状态做分割。[Learned Primal-Dual](https://arxiv.org/abs/1707.06474)以及[task-adapted inverse problems](https://arxiv.org/abs/1809.00948)提供可借用的思路。主目标仍是分割；内部几何状态不自动把恢复升级为主线。

第一版固定大部分观测参数，只研究一个能核实的因素，如采样支持或缺测。不能同时自由估计h、偏差、平滑和错位后声称物理可辨识。现成摄影测量DSM的生成过程未知，K只能称有效近似；有元数据、受控栅格化或独立测量时才能检验物理对应。

最小六臂：普通特征融合；同样加入GSD/有效掩码等元数据；固定插值/滤波后融合；显式一致性更新；去掉一致性但同结构；使用预先指定错误观测算子。各臂看到相同元数据，避免把额外信息优势记成算法优势。

继续条件：在未见采样或缺测条件下，一致性优于简单预处理及元数据拼接，正确算子优于错误算子，且残差改善伴随任务改善。若只降低DSM拟合误差、只在合成数据成立，或正确/错误算子无差别，就停止该机制扩展。这与旧M1调整高度幅度不同，不能把旧负结果说成此路线已经失败。

### 11.3 对应后验：借鉴机器人定位中的鲁棒状态估计

先用同一匹配前端产生RGB–DSM候选对应，再由低自由度几何状态、鲁棒残差和可关闭的错误约束估计位置及其不确定性。借鉴[Switchable Constraints](https://nikosuenderhauf.github.io/assets/papers/IROS12-switchableConstraints.pdf)及[GNC鲁棒估计](https://arxiv.org/abs/1909.08605)。

比较最可能变换下的硬融合与对少量可行变换的预测平均：
`p(y|R,D) ≈ sum_k w_k p(y|R, W_theta_k D)`。
这与对专家置信度再加一个gate不同：估计对象是位置状态，各处对应须满足共同几何约束。

强对照为同候选RANSAC/Huber/GNC硬校正、普通邻域soft matching、候选后验均值硬校正、候选后验传播。不同方法都报告DSM利用覆盖率；不能靠拒绝更多几何赢得“安全”。匹配器相同、增加的推理采样次数与简单多位移集成匹配。

只有后验传播优于硬均值和等成本多位移平均、几何方差与对应误差有关时，才支持不确定性机制。没有真实对应真值则限制结论，不把语义熵冒充几何不确定性。该方法是S的一种具体解法，不是S唯一可行路线。

### 11.4 优化几何：借鉴多任务梯度处理与约束学习

若同一联合模型在clean、RGB退化、DSM退化条件下共享参数，可分别计算这些目标对共享参数的梯度，测量方向冲突与范数主导。M2的独立模型之间不存在共享参数梯度冲突，不能用此解释其尚未产生的结果。

[PCGrad](https://proceedings.neurips.cc/paper_files/paper/2020/hash/3fe78a8acf5fda99de95303940a2420c-Abstract.html)改变冲突梯度方向；[CAGrad](https://arxiv.org/abs/2110.14048)是另一多目标优化对照；[MMPareto](https://proceedings.mlr.press/v235/wei24d.html)已经直接研究多模态联合与单模态辅助目标的关系。它们都值得作为起点和强对照，而不是因有先例就不做。

同模型比较平均loss、固定加权、范数平衡、PCGrad/CAGrad和任务适配策略。固定样本曝光与条件数量，另报多次反传计算开销。负cosine只是现象；只有改变更新方向后，在相同曝光/预算下改善预定义的正常—退化权衡，才能支持机制。若只有梯度统计变好，或单纯调整权重同样有效，就不延伸复杂优化器。

若M2或后续联合模型出现“补救有效但保护失败”，另一候选是显式约束优化：最小化退化损失，同时约束各保护条件相对RGB参考的经验损失增加不超过预定容忍，使用拉格朗日变量更新。借鉴[constrained learning](https://proceedings.neurips.cc/paper/2020/file/c291b01517f3e6797c774c306591cc32-Paper.pdf)。训练CE约束不等于mIoU保护，也不能承诺部署时逐像素不伤害；必须画出与静态权重相同计算预算的收益—损伤前沿。不得用外层评价标签更新约束。

### 11.5 对象关系：借鉴显微图像中的吸引/排斥图分割

让DSM辅助预测位置对是否属于同一实例，形成可信的吸引边、排斥边和未知关系，由固定图解码器输出对象。RGB主要提供语义；几何负责关系约束。这改变输出单位，需真实实例标签。

[Mutex Watershed](https://openaccess.thecvf.com/content_ECCV_2018/html/Steffen_Wolf_The_Mutex_Watershed_ECCV_2018_paper.html)提供局部吸引/较远排斥图分割思路；[Frame Field Learning](https://openaccess.thecvf.com/content/CVPR2021/html/Girard_Polygonal_Building_Extraction_by_Frame_Field_Learning_CVPR_2021_paper.html)是成熟建筑结构基线。移植时不假设同高必同实例、异高必不同实例，也不强制建筑无孔洞或全部正交。

比较RGB连通域/实例基线、DSM梯度watershed、仅RGB关系、RGB+DSM关系、打乱几何关系和成熟矢量方法。第一版冻结共享语义预测，主看对象合并/分裂及对象召回。若普通watershed已等效，或减少合并却明显增加分裂，接受简单方案或关闭该机制。此路线与V绑定，不用Potsdam语义标签伪造实例真值。

### 11.6 测量误差与真实变化分离：借鉴测绘及鲁棒估计

在双时相完整几何机制实验中可写：
`D2(W_theta x) - D1(x) = c(x) + b(x) + epsilon(x)`。
c为真实高度变化，b为低自由度垂直偏差，另有测量有效性变量。大残差不能统一丢弃或统一判变化。

强基线包含[Nuth–Kääb DEM校正](https://tc.copernicus.org/articles/5/271/2011/)；候选改进的机会是局部对应歧义、无效测量与真实建筑变化共存时的分离。限制形变及偏差自由度，先冻结校正再识别变化，检查整栋变化幅度是否被削弱。稳定区域只能从部署可见输入估计；全开发区变化时若缺少锚点，应保留不可辨识性。

这组假设适合局部建筑变化，不能直接外推到大范围沉降/冰川变化；后者的真实变化本身也可能低频。向旧DSM+新RGB迁移是另一输入更少的实验，需重新验证可辨识性。

## 12. 根据最新偏好的具体取舍

建议目前保留遥感几何主领域，先换解法的假设，不因已有研究就转向完全陌生领域。近期可执行设计的优先级调整为：

1. **先做有限的条件几何/表征鉴别。** 将11.1的冻结表示头部对照嵌入J，先回答现有几何信息能否被更好利用。独立DSM语义目标是否限制表示，留给后续实际训练编码器/适配器的独立对照。这是最能利用当前积累的方案。
2. **把测量一致性作为更深入的方法候选。** 在公开数据与观测元数据支持时，11.2与11.3二选一切入，不一开始同时学习所有干扰。它们可形成新的技术主张，但须胜过元数据拼接、重采样、增强和成熟配准。
3. **优化方法按症状选择。** 有共享梯度冲突或明确保护权衡才采用11.4，避免把PCGrad当通用补丁。
4. **若当前语义任务缺少可改善残差，再换输出任务。** 有实例结构问题转V/11.5；有时序几何混淆转T/11.6。不要求J先成功才允许新数据可行性研究。
5. 候选达到“对强基线有实用优势、机制消融成立、跨条件保持”后，继续完整长程验证。创新可以来自对成熟问题更好的处理，无须证明原问题无人研究。

上述是助手推荐，未成为用户采纳的新执行决定。M2原队列与门禁保持；本轮仅完成研究规划并同步记录。
