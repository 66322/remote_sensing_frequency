## Frozen design

Existing C, KD and SAFE selected checkpoints are evaluated without changing them.
New B2-R05 and B2-AVG start from the same R05 checkpoint as B1-KD, not its continued student.
Both use seed42, 4000-step continuation, 4000-step scheduler horizon, warmup200,
patch512, microbatch2, accumulation8, the same AdamW settings and treatments,
T=2 and KL weight0.5. No extra missing-region KL. Only teacher target and identifiers change.
Checkpoint selection remains clean Val2 NoBoundary fg5 every500 steps. Do not select on corruption performance.
Total training history includes the pretrained 16k R05; these are not fresh 4k baselines.

- R05 target: softmax(logits5/T), including missing regions. No fallback.
- Safe-average target: [softmax(logits1/T)+softmax(logits5/T)]/2 outside known missing regions;
  softmax(logits1/T) inside known missing regions. This is averaging temperature-softened
  probabilities, not temperature-softening a T=1 probability mixture and not logit averaging.
- Existing KD uses confidence selection at T=1 then temperature-softened selected targets.
- The same frozen R01/R05 forward passes are kept in both new arms, including unused R01
  forward in R05-only, to match main teacher compute and construction/RNG behavior.
- The known synthetic missing mask is not a learned/general missing detector. The student
  receives only RGB and treated DSM, never GT-derived routing decisions or that mask as input.

## Queue and limits

1. Fast regional evaluator smoke: top-left 512-square crop of the first Val2 tile,
   clean / local-zero-q1 / local-down8-q1. This is smoke evidence ONLY.
2. Full C, KD and SAFE regional evaluations.
3. R05-teacher 20-step training smoke, then 4000-step training and full regional evaluation.
4. Safe-average-teacher 20-step smoke, then 4000-step training and full regional evaluation.

Physical GPU0 only; serial jobs. Independent failures continue, dependent jobs skip;
no retries and no automatic resume. Output directories must not exist.
Global preflight failure launches no jobs. Per-job boundary failure blocks that job.

Expected total 8–10 hours is a planning estimate, not a measured guarantee. Training reference:
user-supplied B1-KD start/end timestamps imply about2h38m for its 4000-step run.
A GPU0-free preflight is mandatory. This queue has a cooperative file lock, but cannot
prevent unrelated programs from starting later; do not launch other GPU0 jobs alongside it.
At least20GiB free disk is required. Approximately three models are resident during training,
matching the previous B1-KD setup; actual peak memory must be taken from run outputs.

Hard budget: at most12 hours of job execution after preflight. Per training job5h;
per formal evaluation2h; each smoke30min. At a hard timeout the queue records the reason,
sends TERM to its child process group, waits up to60 seconds, then KILL if needed.
User interruption also terminates its active child group. No other processes are killed.

## Evaluation and artifacts

11 fixed conditions: clean, global DSM zero/down8, four quadrant zero masks,
four quadrant down8 masks. Same D5 condition constructors and same sliding-window geometry.
No new random masks, severity sweeps, second seeds, optical corruptions, or test6 runs are added.

Each model: whole / damaged / intact / corruption-interface band (+/-8 pixels,
Chebyshev distance). Interface band overlaps damaged/intact; it is not a semantic
boundary metric. Clean has empty damaged/boundary regions; global faults have empty
intact/boundary regions. Empty outputs are NA rather than zero.

Save FullGT and NoBoundary int64 6x6 confusion matrices for each tile/condition/region,
plus pooled matrices; per-class TP/FP/FN/support/union and IoU; class Clutter is excluded
from fg5. Dataset scores are recomputed from pooled counts, not averaged tile IoUs.
Absent classes retain the existing nan-excluding metric convention and are exposed via
counts; compare class support when interpreting small regional scores.

Inference averages overlapping logits before softmax. Argmax matches existing summed-logit
inference; confidence is a separate diagnostic. Thresholds0.7/0.9/0.95 report coverage,
accepted count and error count together. These are NOT matched-coverage comparisons,
NOT pseudo-label training, and NOT calibrated probabilities or proof of a mechanism.
GT is used only to count evaluation errors; it never controls inference.
