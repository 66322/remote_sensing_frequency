# 当前研究决定：登记M2错误对应性长程实验设计（2026-10-16）

## 阶段与来源

用户在已完成M1验收后明确要求：“根据实验结果和问题，安排下一阶段的实验，可用GPU0和GPU1，时间不限，实验规划尽量长。”研究优先级仍为问题与创新性。助手据此完成问题论证与具体设计登记；属于重写版建议/待验证方案，不能倒写成新方法贡献或已有实验结果。

研究主线仍为RGB–DSM双向条件互补及退化/缺失分割；恢复为旁支。新干预从输入幅度/输出门控移至训练监督的困难位置对应性。普通难例训练、类别/边界分层打乱、熵排序和直接固定融合损失均列为竞争解释。已有boosting/残差学习先行工作，不能以“用RGB错误训练DSM”自称首创。

[M2计划](../protocols/PHASE3_M2_ERROR_CORRESPONDENCE_20261015.md)：仅从原Fit12做三路外层分组，全部模型从公共预训练重新训练；每格4个train6交叉拟合RGB教师、1个train8 RGB参考和7个DSM目标对照。seed42/17/2026覆盖整个系统。核心108×32k=3,456,000更新，随后完整3×3 RGB实例换配及预设未见退化。

仅核心G0–G4全通过才进入反向90作业；第二编码器81作业还需精确架构/初始化/执行合同冻结。总279是预算上限，不是无条件队列。固定α=.1失败须结合margin/权重曲线解释，不扩大成信息无用。
