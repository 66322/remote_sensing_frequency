# 下一步：先形成可行性判断，再选择有界实验

研究定位以[研究决策说明](https://github.com/66322/remote_sensing_frequency/blob/37adbaf5fb11a56b41052d3685565f418e9df8cb/docs/current/RESEARCH_DECISION.md)为准。当前是可行性探索；频率与语义可靠性融合是优先评估候选，允许换解法、换交叉问题或换方向。C1为旁支候选，尚未被选为替代主线。这里的工作顺序取代此前“唯一下一门禁为C1外部评价”的表述。

## 立即工作：利用已有证据梳理未决问题

形成一张机制证据表：研究假设 → 实际实现与执行分支 → 匹配对照 → 训练缺失/退化条件 → 推理可用输入与回退方式 → 评价/原门槛 → 结果边界 → 尚未回答的问题。沿入口、配置、forward、损失与反传、评价链核对，不按模块名称判定。

优先回答三个问题：辅助模态互补性与负迁移问题是否值得继续；哪些频率/语义可靠性解法已被有效测试或排除；还缺哪个足以改变去留决定的检验。注意D11/D12等探针、D13/D16/D17等具体实现以及D21/Post-D21的任务和口径差异；不要重复已关闭筛选或把局部失败扩大为全类机制无效。

交付应明确提出“继续具体解法／同题换解法／换交叉问题／换方向或停止”的证据支持建议，并标注仍待决定事项。当前没有冻结新的训练矩阵；不要把本文件当启动命令。

## 支持性工作：补轻量原始证据

按拟作判断的需要，收集已有运行的训练/评价摘要、int64 6×6矩阵、逐tile计数、配置与checkpoint绑定、完成标记和SHA清单。Post-D21完整摘要仍在服务器，紧凑JSON不能代替全部原始矩阵复算；可先补E四组，再按待审问题补42项。缺归档应补归档，不重跑训练。无需为了矩阵复算下载全部预测和权重。

## 选定候选后才冻结实验

- 保留可靠性融合问题：明确一个实质新假设，设置光学基线、相同增强的普通融合及必要容量/机制消融，覆盖正常、整幅/局部缺失和退化；分开评价工程回退与精度保护。阶段若只涉及DSM，不称任意模态鲁棒。新增对照按问题选择，不把所有历史模型重新排队。
- 选择C1备选：可设计冻结C0/C1的独立地区成对评价，或容量归因对照。C1本身已是双三次后的三层残差CNN，不能把同一CNN换名充当容量对照。上述是条件方案，不是已决定转向。
- 选择新交叉问题/方向：先写清已有证据为何支持该问题、预期贡献和最小区分实验，不为填充既定章节堆叠模块。

任何新训练前按[准备规则](https://github.com/66322/remote_sensing_frequency/blob/37adbaf5fb11a56b41052d3685565f418e9df8cb/docs/protocols/EXPERIMENT_PLANNING_RULES.md)与[准备表](https://github.com/66322/remote_sensing_frequency/blob/37adbaf5fb11a56b41052d3685565f418e9df8cb/docs/templates/EXPERIMENT_PREFLIGHT_TEMPLATE.md)冻结预算、单seed默认、匹配条件、判定与停止规则，并完成有界吞吐检查。多种子用于明确的稳定性问题，不能挽救失败门槛；不自动下载或排长队。

## 外部来源的条件与边界

独立数据准备可与机制分析并行，不阻塞已有数据的合理探索。只有开展外部评价时才要求来源、许可、空间隔离、RGB/IRRG通道、GSD、类别映射、配准、访问路线、体量和SHA验收；冻结模型到目标数据的映射，不用目标标签择优或调参。类别不兼容时只报可比类别分项，不套用原fg5。

Test6及独立final保持既有封存边界。旧C1执行优先级见[历史快照](https://github.com/66322/remote_sensing_frequency/blob/37adbaf5fb11a56b41052d3685565f418e9df8cb/docs/history/20261001_before_strategy_clarification/docs/current/NEXT_EXPERIMENT.md)，不作为当前指令。
